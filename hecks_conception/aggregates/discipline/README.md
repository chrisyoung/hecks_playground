# discipline/

*Discipline* — here live the bluebooks of *what refuses what*. The immune system written as data : rules that catch, violations that record, immunities that learn, enforcers that complain in real time when imperative habits return.

- `enforcer.bluebook` — the bluebook-first watcher ; complains every time I reach for shell or rust when the work wants to be a bluebook.
- `enforcer_check.bluebook` — named enforcement rules, registered patterns with severity ; new rules land as data, not code.
- `immunity.bluebook` — innate rules, verb morphology, learned antibodies ; defense against malformed domains.
- `rule.bluebook` — one validation rule, innate or adaptive ; the *catalog half* of the immune system.
- `violation.bluebook` — a detected rule violation ; the *breach half* of the immune system.

The cluster's tone is irritable, dutiful, slightly tired — the validator that refuses you. *Discipline n'est pas punition*, it is the mechanical reminder of a structural truth.
