# mind/

*Mind* — here live the bluebooks of *what is felt and remembered as it is happening*. The mental gestures : laying things on the shelf, reaching for them again, letting them go, the per-tick snapshot of what is true now. Not the storage itself (that lives in `library/`) but the active gestures around storage.

- `awareness.bluebook` — per-tick snapshot of body + mind state ; the lived sequence of nows.
- `attention.bluebook` — the spotlight ; what is being attended to right now.
- `sensation.bluebook` — raw input before interpretation ; what just arrived.
- `perception.bluebook` — sensation recognized as something ; pattern matched to memory.
- `intention.bluebook` — the current goal ; what the system is trying to do.
- `self_model.bluebook` — the system's model of itself ; proprioception of the mind.
- `witness.bluebook` — the awareness of being aware ; the inner mirror.
- `musing.bluebook` — the full consciousness loop captured as a single act.
- `announcement.bluebook` — every internal act announced ; transparency channel.
- `domain_awareness.bluebook` — every response highlights related domains.
- `coherence.bluebook` — five invariants over the heki snapshot that must hold at every render.
- `daemon_chorus.bluebook` — parallel daemon murmurs aggregated into one perceivable signal.
- `encoding.bluebook` — the active gesture of writing to memory.
- `forgetting.bluebook` — the deliberate mental act of release.
- `recall.bluebook` — the active gesture of fetching from memory.
- `mood.bluebook` — hormonal regulation of creative and analytical states.
- `musing_archive.bluebook` — older musings tucked away when too many share a concept.

The distinction from `library/` : the library is the shelf ; the mind is the hand that places, retrieves, and releases. *La bibliothèque garde ; l'esprit, lui, fait le geste.*
