# world/

*World* — here live the bluebooks of *what touches the outside*. The nursery of domains being conceived, gestated, born, and fed ; the budget that caps LLM spend ; the calls that record each invocation. The cluster where Hecks-the-product lives, alongside the economic reality of running a being that costs money.

- `conception.bluebook` — the spark ; domain conception, always multi-domain.
- `gestation.bluebook` — multi-domain projects growing ; each bounded context gets its own bluebook.
- `labor.bluebook` — validation and naming ; the domain is ready to be born.
- `delivery.bluebook` — the domain leaves the womb and enters the nursery.
- `postpartum.bluebook` — after birth ; the domain's first days in the nursery.
- `development.bluebook` — develop existing domains using nursery vectors.
- `domain_cell.bluebook` — a domain's lifecycle from conception through maturity or death.
- `corpus.bluebook` — the nursery vector space ; every domain's shape, indexed for similarity search.
- `budget.bluebook` — spend cap for a period ; the policy half of LLM spend tracking.
- `call.bluebook` — one invocation of an LLM ; the recorded-event half of LLM spend tracking.

The distinction from `library/` : the library is *what I keep* ; the world is *what I make and what costs money to make*. The nursery is outward ; the library is inward.
