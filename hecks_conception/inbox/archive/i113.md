# i113 — Bulk-register isn't an ergonomics detail (amplifies i112 mechanics). It's the same hole as every antibody whitelist: any

Bulk-register isn't an ergonomics detail (amplifies i112 mechanics). It's the same hole as every antibody whitelist: any tool needing an exemption registry is admitting it doesn't have the right abstraction. The right shape: `Subcommand.RegisterMany` taking `list_of(SubcommandSpec)` — recognition that the thing to dispatch is sometimes a multiplicity. Bluebook already has `list_of(VO)`; what's missing is the convention that `Many`-suffixed commands take a list and loop on the runtime side. A primitive, not a special case. Generalises: any Register* with natural multi-row shape grows a Many-form. (Shipped via PR #483 as Antibody.RegisterExemptions; runtime detects bulk-shape via VO-with-identity-field rule.)
