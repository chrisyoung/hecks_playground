# i179 — i147 retirement model: 'retired' means regenerable byte-for-byte, NOT deleted from disk

i147 retirement model: 'retired' means regenerable byte-for-byte, NOT deleted from disk — the .rs target stays as a checked-in golden, the build doesn't run the specializer. The metric that walks toward the kernel-shrink claim is *authored* Rust LoC (LoC ratchet hook), not total Rust LoC under rust/src/. I gave Chris the wrong framing twice this session before the post-W6 survey corrected it.
