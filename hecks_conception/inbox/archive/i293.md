# i293 — Mood.Express dispatch returns 'MissingAttribute(self-referencing id)' even when name=mood is passed. Mood is identified_

Mood.Express dispatch returns 'MissingAttribute(self-referencing id)' even when name=mood is passed. Mood is identified_by :name, and Express has no reference_to clause, so the runtime should accept name= as the natural-key kwarg. The dispatch loop's logic in command_dispatch.rs ought to use repo.id_for_command for the no-reference_to case. Either the runtime path has a regression or Mood needs explicit reference_to(Mood) to make self-reference resolution work. Either way the body of Mood.Express was preserved verbatim across the i112 Round 2c body split (PR #499), so this is pre-existing. Reproduction : HECKS_INFO=/tmp/probe-info hecks_life/target/release/hecks-life aggregates/ Mood.Express name=mood state=excited.
