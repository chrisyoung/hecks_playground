# i305 — policy-attr-mapping ergonomics gap surfaced after i161 close. Evaluation.EvaluateModel declares 3 required Float attrs (

policy-attr-mapping ergonomics gap surfaced after i161 close. Evaluation.EvaluateModel declares 3 required Float attrs (bluebook_accuracy, conversation_quality, behavior_adherence) ; the EvaluateOnComplete policy on FineTuneCompleted has no map clause supplying them, so the cascade dispatch fails on missing-attribute when the i161 routing now correctly hits Evaluation.EvaluateModel instead of summer.bluebook's payload-free EvaluateModel. Fix shapes : (a) add map to EvaluateOnComplete that supplies sensible defaults (zeros and pending status) ; (b) make EvaluateModel's required attrs optional with defaults ; (c) lift the metric attrs into the FineTuneCompleted event so the cascade carries them through. Acceptance : fine_tune.behaviors CompleteFineTune cascades through policy chain test (currently :pending with a new reason) flips to passing.
