# i310 — Acronym-casing parity drift between Ruby and Rust snake_case converters. Ruby ActiveSupport treats consecutive uppercase

Acronym-casing parity drift between Ruby and Rust snake_case converters. Ruby ActiveSupport treats consecutive uppercase as single unit (DNAProfile → dna_profile); Rust inserted underscores between each transition (d_n_a_profile). Fixed in PR #316 — ported Ruby inflector algorithm to Rust, 15 unit tests, 3 real bluebooks unblock immediately (radiology_clouds, refugee_identity, water_quality_api). Others will unblock as their upstream drift classes resolve.
