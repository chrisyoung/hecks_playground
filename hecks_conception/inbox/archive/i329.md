# i329 — (SHIPPED via PR #483) Antibody.RegisterExemptions accepts either form: per-row dispatch as today, OR a one-shot bulk com

(SHIPPED via PR #483) Antibody.RegisterExemptions accepts either form: per-row dispatch as today, OR a one-shot bulk command taking list_of(ExemptionSpec). Bulk seeds aren't an escape hatch — they're a real domain operation. Same pattern as Subcommand.RegisterMany (i113): Register* commands with natural multi-row shape get the Many-form alongside the singular. Antibody is the proving ground because the registry is most visible there (the audit channel logs every out-of-band write that *would* have been an exemption). Implementation in PR #483: ExemptionSpec VO with path+reason; Antibody.RegisterExemptions takes list_of(ExemptionSpec); runtime detects bulk-shape automatically (one list_of(VO) attr where VO carries the aggregate identity field) and iterates, emitting one event per row. Tested with 38-spec bulk equivalent of the i112 catalog seed shape.
