# i334 — Four hecksagon-parity drift classes surfaced during i7 parsed hecksagon/world DSL work (PR #325). Ruby allow-list loader

Four hecksagon-parity drift classes surfaced during i7 parsed hecksagon/world DSL work (PR #325). Ruby allow-list loader parses cleanly but produces IR that differs from Rust hecksagon_parser output in four recurring ways:

1. Trailing whitespace / newline normalization between builder chapter blocks.
2. Empty-list vs omitted-field representation in `.capabilities` and similar (Ruby emits `[]`, Rust omits the field).
3. Ordering of sibling aggregates when declared in alternating chapter groups (Ruby preserves source order across chapter boundaries; Rust groups by chapter first).
4. Number-type inference on integer-looking strings (Ruby casts early in the builder, Rust defers until validation).

Each class is small; together they block flipping hecksagon+world from soft-parity to hard-parity. Plan: one PR per class, fixtures first (spec/parity/hecksagon_known_drift.txt + world_known_drift.txt), then tighten the loader until each drift entry disappears. Relates to i31 (expand parity coverage); likely shipped alongside i31 rather than standalone.
