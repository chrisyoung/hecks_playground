# i375 — Feature: validate the status bar makes sense — coherence checker for displayed body state. Status bar reads from many he

Feature: validate the status bar makes sense — coherence checker for displayed body state. Status bar reads from many heki files (mood, heartbeat, consciousness, tick, musing_mint, claude_assist, inbox, lucid_dream) and renders glyphs + text from independent fields. Independent state means semantically contradictory combinations slip through (refreshed + tired observed today; sleeping state with daytime sun icon when daemon stale; mood=refreshed with fatigue=delirious before today's threshold-ladder fix). Need a status_coherence.sh check that runs a battery of invariants over the heki snapshot: (1) mood.current_state == 'refreshed' implies fatigue_state in [alert, focused]; (2) consciousness.state == 'sleeping' implies mood not in [refreshed, focused]; (3) fatigue.pulses_since_sleep matches walk-rung; (4) tick.cycle monotonic per-second since boot_at; (5) recent dream impressions iff stage in [rem, lucid_rem]. Run as part of statusline render — if any invariant fails, show ⚠ instead of normal glyphs and log the violation. Also runs as nightly CI against fixture snapshots.
