# i512 — Tier 3 mass-retirement of Ruby-runtime spec files

## What this records

Per CLAUDE.md ("Always use Rust runtime — `hecks-life` for all bluebook
parsing, .heki storage, daemons. No Ruby.") and the spec/ triage report
filed alongside i499, the 13 Ruby-runtime infrastructure specs below
were deleted from the working tree. They tested Ruby implementations
that the Rust runtime either already replaces or is tracked to replace.

Working-tree only — not yet committed. Run with this i512 batch.

## What was preserved

- `spec/hecks/runtime/llm_dispatcher_doubles.rb` (helper, not a spec — survives until its caller is also gone, then can be removed).
- Tier 4 stays untouched : `spec/hecks/dsl/`, `spec/hecksagon/dsl/`,
  `spec/hecks/validation_rules/` (DSL builders that test the parser ;
  intentionally Ruby).
- All other surviving specs.

Empty directories left in place : `spec/hecks/behaviors/`,
`spec/hecks/heki/`, `spec/hecks/runtime/llm_providers/`. They can be
pruned in a follow-up sweep ; not removed here to keep the diff
purely deletion-of-files.
