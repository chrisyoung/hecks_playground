# i524 — behaviors_conceiver.bluebook : conceive the test scaffolder

**Filed:** 2026-05-09
**In service of:** dream-work — close the **biggest** bluebook-first gap in the codebase. `rust/src/behaviors_conceiver/generator.rs` is **1579 LoC** of imperative test scaffolder, with no bluebook describing what it generates.

## Gap

`rust/src/behaviors_conceiver/generator.rs` is the engine that takes
a `.bluebook` + `.hecksagon` + `.fixtures` cluster and emits a
`.behaviors` file — the BDD-style test scaffold that runs against
the runtime. It generates :

  - One `behavior` per command + per lifecycle transition.
  - `given` blocks from fixtures.
  - `when` blocks dispatching the command.
  - `then` blocks asserting on emitted events, lifecycle changes,
    cascade dispatches, projection updates.

This is the **biggest unbluebooked file in the codebase**. No
domain captures the contract between an aggregate's structure and
the behaviors-suite that should test it.

## Proposal

Conceive `codegen/behaviors_conceiver/behaviors_conceiver.bluebook`.
The bluebook should name :

  - **BehaviorScaffold** (aggregate, lifecycle: pending|generated|emitted)
    - aggregate_name : String
    - command_count : Integer
    - transition_count : Integer
  - **Behavior** (value object)
    - name : String
    - given : list_of String
    - when : String
    - then : list_of String
    - cascade_expected : list_of String
  - Commands :
    - **Conceive**(aggregate, fixtures) — derive scaffolds
    - **Emit**(target_path) — write .behaviors file

The patterns embedded in 1579 LoC (one behavior per command, given
from fixtures, then on emitted-event, cascade-trace, lifecycle-state)
are the **rules** of the test scaffolder ; making them declarative
in a bluebook means they're inspectable, modifiable, and
specializer-regenerable.

## Why this matters

This is the largest gap by line count. Closing it transforms 1579
LoC of "what test gets generated" from imperative code into
declarative pattern. The test scaffolder is itself testable then —
fixtures + bluebook → expected behavior file shape.

## Out of scope

Refactoring the 1579 LoC. Just conceive the bluebook ; the
specializer (i147 wave) can later regenerate the .rs from it.

## Acceptance

  - `codegen/behaviors_conceiver/behaviors_conceiver.bluebook` exists.
  - Parity stays 330+.
  - The kernel-floor Rust file's antibody marker is updated to
    reference this bluebook as its specification.
