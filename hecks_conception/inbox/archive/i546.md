# i546 — Universe view differentiated from single-domain diagram

## Why this card exists

In the worker today (`diagram_universe` handler in lib.rs) :

```rust
fn diagram_universe(_req, _ctx) -> Result<Response> {
    let (runtimes, primary) = boot_runtimes();
    let html = storehouse::server::html_diagram::generate(&primary, rt);
    Response::from_html(html)
}
```

Same code as `diagram_domain` — just uses the primary domain's name.
The dev server has a separate path for `_all` that emits "🌌 The
Universe" and renders every loaded domain as a labeled cluster with
cross-domain reference edges.

## What changes

In the worker (or framework `html_diagram` module) :

- `/diagram` (no path param) → use the universe template with
  `domain_name = "_all"`, render the universe cluster view via
  `html_diagram::all_domains_graph_view(runtimes)`.
- `/diagram/:domain` → today's behavior (single-domain diagram).
- `/diagram/_all/graph.json` → returns
  `html_diagram::all_domains_graph_json(runtimes)`. See i548.

The universe view title becomes "🌌 The Universe — Living Diagram"
and the page subtitle reads "Every loaded bluebook in this app".

Even with only BinBuddy loaded today, the universe view is
meaningful — it labels the cluster and shows the cross-domain
references when more domains are eventually embedded.
