# i100 — RestartPrompt domain + daemon (2026-05-19)

## What landed

The `RestartPrompt` domain and `restart-prompt-daemon` are shipped on
branch `sq/restart-prompt-daemon`.

**Bluebook** :
`hecks_conception/aggregates/framework/restart_prompt/restart_prompt.bluebook`

- Aggregate `RestartPrompt` — singleton identified by `name` (default `"miette"`)
- Attributes : `latest_content`, `latest_at`, `latest_session_id`, `total_compositions`
- Command `Compose(content, session_id, composed_at, total_compositions)` → emits `Composed`
- Entity `Composition` (audit trail per compose)
- 4/4 behaviors passing

**Daemon** (Shape B — standalone bin script) :
`bin/restart-prompt-daemon`

- Runs `storehouse follow RestartPrompt` (long-running tail)
- On `event RestartPrompt.Composed` : queries singleton state, writes
  `hecks_conception/inbox/restarts_inbox/latest.md` with YAML frontmatter + body
- `[antibody-exempt: kernel-floor daemon for the i645 RestartPrompt mindstream member — declarative shape lives in the bluebook]`

**Procfile entry** :
```
restart_prompt: bin/restart-prompt-daemon
```

**mindstream.fixtures** : `restart_prompt` MindstreamMember registered,
`lifespan: persistent`, auto-restart on crash.

**Output artifact** : `inbox/restarts_inbox/latest.md` — the canonical
orientation artifact the next session pastes in verbatim.

## Closes when

Merged to main and overmind is restarted to pick up the new Procfile entry.
