# i102 — primitive-envy-sweep-bluebooks-to-value-objects

primitive-envy-sweep-bluebooks-to-value-objects — Bluebooks across the corpus are suffering from primitive obsession. Attributes typed `String`, `Integer`, `Float` are doing semantic work that wants its own type — `wish_id: String`, `ref: String`, `status: String`, `priority: String`, `fatigue: Float`, `sleep_stage: String`, `is_lucid: String` (yes, a Y/N flag is a String), `provider: String` (claude|local|off — an enum-shaped String), `mood: String` (refreshed|excited|focused|... a closed vocabulary as a free-text String). Each of these is a value object pretending to be a primitive. The smell shows up loudest in references : `reference_to(DreamWish)` is fine because DreamWish is an aggregate, but every attribute typed `String` that names a domain concept (id, ref, status, mood, stage) is a missed value object. Eric Evans, were he to see how we do primitive references, would die just so he could turn over in his grave. Sweep work : (1) walk every aggregates/*.bluebook + capabilities/**/*.bluebook + nursery/**/*.bluebook ; identify attributes whose name carries semantic weight (id-shaped, enum-shaped, currency-shaped, email/url-shaped, date-shaped) ; (2) declare value objects for each — `value_object "WishId" do ; format /^w\d{8}T\d{4}Z_\d+$/ ; end` or `value_object "Mood" do ; one_of "refreshed", "excited", "focused", "curious", "drifting", "groggy", "vivid", "sleeping" ; end` ; (3) replace primitive types in attribute / reference_to / command-arg declarations with the value-object names ; (4) the runtime gains a value-object kind in the IR ; the validator type-checks references through it. DSL gap : today the bluebook has `attribute :foo, String` but no `value_object` keyword. Companion to i101 (query-as-first-class-IR) — both are DSL strengthening : queries gain shape, types gain shape. Sibling of all the form-tightening arc (DSL ergonomics like i100 then-set-shorthand, reference_to(Klass) shorthand). Filed 2026-04-26 after the dream_wish.bluebook session showed how many primitives are doing semantic work : id, status, filed_as, ref, recorded_at — every one of those wants a type.
