# i114 — Antibody self-introspects against the bluebook IR

Antibody self-introspects against the bluebook IR. Rather than a registry of exemptions, a validator that asks the bluebook: 'is this script already dispatched by you?' before refusing. When yes, exemption is implicit. When no, hook blocks as today. Same inversion as dump_shape (Phase D Rust-native specializer): instead of patching the output, we ask the grammar to generate the rule. Meta-shape for antibody. Retires the exempt_registry as data — replaces it with a query against the IR. Closes the structural reason i112/i113/i116 exist as filings: the validator's '-ment classifier choking on its own exceptions' pattern is the antibody's scar tissue made visible. Body-cycle audit: 86 reach-pasts vs 1 production dispatch in shell — most retire under this rule.
