# i131 — DDD: Aggregate roots as enforced. In strict DDD the aggregate root is the only allowed external entry point

DDD: Aggregate roots as enforced. In strict DDD the aggregate root is the only allowed external entry point — no one references entities directly from outside. The runtime doesn't enforce this today ; an external caller could in principle dispatch against any entity. The discipline is conventional, not structural. With the new `entity` primitive (PR #482) we declare entities, but external dispatch against `Phase.End` (where Phase is an entity inside Cli) isn't blocked. Proposed: runtime gates dispatch by aggregate-root scope ; entities are reachable only as nested attribute paths on the root. Acceptance : `hecks-life X.EntityCommand args` where X is an entity (not a root) returns 'Entity not externally addressable' instead of dispatching.
