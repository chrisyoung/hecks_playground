# i132 — DDD: Process managers / sagas as first-class. Long-running cross-aggregate processes

DDD: Process managers / sagas as first-class. Long-running cross-aggregate processes — a sleep cycle progressing through phases, a dream session accumulating observations and consolidating them into memory — deserve to be first-class artifacts. Today they're cascades of policies, which works but doesn't give you the named long-running process as something you can introspect, pause, resume, audit. FEATURES.md mentions process managers exist (on(event_type, correlate:, transition:)) but the conception doesn't actually use them. Proposed shape: `process_manager "SleepCycle" do; correlates_by :name; on 'EnterSleep' → state 'light' → state 'rem' → state 'nrem' → state 'final_light' → end_when 'WakeUp'; end` — the lifecycle of the process becomes a single artifact instead of being scattered across N policies.
