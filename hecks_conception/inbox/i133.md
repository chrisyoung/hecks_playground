# i133 — DDD: Factories as first-class. Complex aggregate construction

DDD: Factories as first-class. Complex aggregate construction — when an aggregate needs setup that's more than just attribute defaults — has no `factory` keyword today. We use Create commands with elaborate then_set chains, which works but conflates 'command that persists' with 'constructor logic that knows how to assemble'. Proposed shape: `factory "NewSleepCycle" do; produces SleepCycle; needs target_total: Integer; assembles { … }; end` — separable from Create command, callable from policies, testable in isolation. Retires the long then_set chains in Create commands across the corpus.
