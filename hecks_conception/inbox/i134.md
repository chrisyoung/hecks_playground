# i134 — DDD: Bounded context maps

DDD: Bounded context maps — name the relationship between contexts. When two contexts (bluebooks) need to talk, DDD names the relationship type : Customer/Supplier, Conformist, Anti-Corruption Layer, Open Host Service, Published Language. Today we have multiple bluebooks talking via shared event bus, but the relationship types aren't named or made structural. The implicit assumption is that everything's a Published Language — but the cross-bluebook policy subscriptions we just shipped (LucidDream → LucidMonitor in PR #497) actually want the ACL or Conformist framing. Proposed shape: `context_map "LucidDream → LucidMonitor" type: :acl` declared once, attached to the cross-bluebook event subscription. Makes coupling explicit instead of accidental.
