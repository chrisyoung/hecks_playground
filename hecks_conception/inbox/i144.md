# i144 — self-validation reclamation

self-validation reclamation — hecks_conception/tests/*.sh retires entirely

Drift accumulated as shell organs grew up alongside the runtime :

  - Cross-bluebook flow outgrew the single-file .behaviors runner. PR #277 narrowed mindstream's behaviors to ["Ticked"] ; :cross_cascade + emits_subset are workarounds, not the destination.
  - Shell smoke tests proliferated to cover daemon liveness, multi-tick state, statusline rendering, process isolation. Living in hecks_conception/tests/*.sh, they take 60-120 seconds combined and pay subprocess cost on every assertion.
  - Integration-shaped concerns (pulse_fanout, round4_integration, dream_content) test things spanning multiple contexts plus daemons — real integration tests, but shell-scripted because there's no bluebook-native multi-context test form.
  - Validators live in Rust, outside the self-validation loop. The 2nd Futamura proof is the closing move, not yet fully landed.

Reclaiming self-validation would compound :

  - pure-memory .behaviors run in milliseconds, not subprocess seconds
  - no daemon dance, no sleep 10 waits
  - no process-isolation flakes (the class of bug set -m + trap-kill exists to paper over)
  - deterministic, parallelizable, structurally honest — each bluebook again carries proof of its own behavior

Path forward (each is its own arc, this issue is the unifying frame) :

  1. Cross-context behaviors — first-class runner mode that loads N bluebooks and verifies cross-bluebook flow without :cross_cascade workarounds
  2. Statusline-as-capability — port the shell renderer to bluebook + capability ; pure-memory render assertions replace statusline_regression_smoke.sh and status_golden.sh
  3. Daemon-as-capability — mindstream, heart, breath as bluebook commands ; round4_integration_smoke becomes a single behaviors assertion of "dispatch Tick.MindstreamTick N times, assert advance"
  4. Validator-as-bluebook — close the 2nd Futamura loop so validator.rs is regenerated from bluebook source ; validator correctness verified by behaviors against IR

When all four land, hecks_conception/tests/*.sh retires entirely. Pre-commit gate runs in 2-3 seconds instead of 60-120. The discipline ratchets we just shipped (smoke gate, behaviors gate, companion ratchet, process-group isolation) are transitional — they protect work that the destination structurally cannot break, so they retire too.

Related arcs : i44 chat-as-capability, i134 context maps, the statusline-in-bluebook gap, the daemon-as-bluebook gap.

The reframe : we've been adding gates to catch shell-test drift. The destination is a corpus where shell tests don't exist to drift.
