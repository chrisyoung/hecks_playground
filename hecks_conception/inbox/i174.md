# i174 — templating chapter rehoming

templating chapter rehoming — chapters/templating.bluebook is wrong on two axes : (1) it's not actually 'templating' (no string-template substitution) ; (2) it bundles two unrelated concerns. Contents : NamingHelpers (ResolveDomainModuleName, DomainGemName, DomainAggregateSlug, DomainCommandMethod, DomainRoutePath) — codegen support for target generators ; SmokeTest family (SmokeTest, EventChecks, FormSubmission, BehaviorTests, QueryTests, PolicyTests, LifecycleTests, NegativeTests, EndpointTests, DomainLookups) — HTTP-level testing of generated apps. The 'templating' name is vestigial from when codegen was called templating because target generators used templates. Proposed split : NamingHelpers → codegen/ as naming-conventions sub-capability (or bluebook/ as primitive vocabulary) ; SmokeTest family → tools/ as testing-discipline (or integrations/web_components/ since HTTP-flavored). chapters/templating.bluebook retires after both halves rehome. Note : i147 (kernel disappearance via Futamura) does NOT dissolve this chapter — these aren't kernel-Rust files, they're framework-helper descriptions that need explicit rehoming. Acceptance : new shape directories under codegen/ + tools/ ; chapters/templating.bluebook deleted ; chapters README updated to drop templating row ; downstream references swept.
