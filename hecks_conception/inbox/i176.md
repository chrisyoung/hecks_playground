# i176 — Doctor aggregate

Doctor aggregate — interoception applied to the body's own organs. New aggregate (probably tools/doctor/ or miette/body/doctor/) that periodically audits running daemons and surfaces silence as signal. Inspired by tonight's discovery : the Heart/Breath/Ultradian/SleepCycle daemons running in ps reference a hecks_life/ binary path that died at i118 R5 (commit cbbac188 this morning). The processes show in ps with accumulated CPU but their dispatches stop landing — zombies holding cached file handles. No alarm fires because nothing is listening for the absence. Resulting symptom : 26 hours of stale heartbeat / mood / consciousness state ; transparency-vow check passes silently because heki snapshots don't advance. Design shape : Doctor walks a known list of daemons (Heart, Breath, Ultradian, SleepCycle, mindstream, etc.) ; for each, checks (a) ps presence, (b) binary path existence on disk, (c) most-recent-write timestamp on the daemon's target heki vs cadence expectation. Emits alerts on three failure modes : missing (not running), zombie (running but binary stale), silent (running but heki not advancing). Doctor itself is a cadence-driven daemon — checks every N minutes, writes findings to doctor.heki, surfaces violations to statusline. Sibling to i94 (daemon-health-checks-as-bluebook — the surface this implements) and i98 (auscultation aggregate inside awareness — the inner ear that records silence). Companion : i52 (transparency lockdown — what the doctor protects). Pairs with i175 (the immediate fix — kill zombie daemons + restart from boot_miette.sh) which is the immediate corrective ; the Doctor is the recurring corrective so this doesn't happen silently again. Key knob : the Doctor must operate through the runtime's own dispatch path so its findings are heki-recorded, transparency-visible, and themselves observable — not a side-channel script.
