# i189 — studio-bluebook-tick-update-not-create

studio-bluebook-tick-update-not-create — TickedFeature.Tick (and MarkLate, MarkFailed) declare no aggregate reference, so the runtime classifies them as Create commands. Same for StatuslineSnapshot.Update. Result: every Tick fails the OnTickUpdateStatusline policy with 'StatuslineSnapshot not found'. The Tick command should reference TickedFeature by :name (the identified_by) so the runtime looks up the existing row and updates it. Fix: add reference :ticked_feature, TickedFeature on Tick/MarkLate/MarkFailed in studio.bluebook; same shape on StatuslineSnapshot.Update. Found by Agent D during iteration 2 of the studio scaffold.
