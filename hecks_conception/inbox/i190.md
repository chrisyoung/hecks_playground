# i190 — lifecycle-from-array-syntax-validator

lifecycle-from-array-syntax-validator — Lifecycle DSL accepts transition 'X' => 'state', from: ['a','b','c'] (array of allowed source states) but the validator rejects it: 'Unsafe lifecycle state [...] : must start with a lowercase letter and contain only lowercase letters, digits, and underscores'. Studio.bluebook + tools/inbox/inbox.bluebook + runtime/server/server.bluebook all hit this warning. Fix: either DSL should expand array form into one transition per source state, or validator should special-case the array form. Cosmetic but spammy — every boot logs four warnings.
