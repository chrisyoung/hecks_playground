# i191 — event-bus-on-any-listener-leak

event-bus-on-any-listener-leak — runtime.event_bus.on_any has no unsubscribe primitive. The studio's commands_handler.rb adds one listener per dispatch to capture emitted event names. The captured array is local so dispatch results stay correct, but listener count grows linearly with requests. Fix: add EventBus#off_any, or scope-bounded subscription block (with_event_capture { ... }). Found by Agent D.
