# i193 — rust-runner-hardcoded-phases-not-bluebook-walker

rust-runner-hardcoded-phases-not-bluebook-walker — rust/src/run_boot/mod.rs hardcodes the Boot pipeline phases as Rust function calls (phase 1: discover::count_organs, etc.) rather than walking the bluebook's lifecycle/policy declarations. Adding StartStudio (Phase 9) to runtime/boot/boot.bluebook does NOTHING in the Rust runner — the new phase is bluebook-only. boot_miette.sh launches the studio as a transitional shell adapter. Companion to i180. Fix: convert the runner into a bluebook walker that dispatches each phase via its declared policy chain.
