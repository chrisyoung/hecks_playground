# i199 — consciousness-callers-must-pass-timestamps

consciousness-callers-must-pass-timestamps — Companion to i196/i197 fix: Consciousness.EnterSleep now requires sleep_at and Consciousness.WakeUp now requires wake_at (ISO-8601 UTC). Any autonomous daemon, shell wrapper, or hook that dispatches these commands must pass the timestamp explicitly — same convention CompleteFinalLight already uses for wake_at. The autonomous-EnterSleep daemon that surfaced i196 (sleep_session.sh / sleep_cycle.sh / unknown — Chris saw 'settling into light sleep (2:00)' on his bar without an identifiable dispatcher script in body/sleep/) needs sleep_at=$(date -u +%Y-%m-%dT%H:%M:%SZ) added to its dispatch line. Same for any wake-side automation (wake_session.sh equivalents). If no such script is checked in and the dispatch is happening from somewhere else (mindstream policy chain, MCP tool, statusline), surface that path and add the timestamp source there. Sweep grep: 'entrypoint=Consciousness\.(EnterSleep|WakeUp)' across the whole stack.
