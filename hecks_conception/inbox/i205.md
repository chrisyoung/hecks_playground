# i205 — heki-append-stderr-noise

heki-append-stderr-noise — Rust runtime emits '[heki:append] out-of-band:' lines on stderr even for successful appends. Exit code is 0 so dispatch wrapper doesn't tag them as failures, but the noise will pollute /tmp/daemon_errors.log and any future studio dashboard surfacing of it. Fix: route the breadcrumb message to a separate log channel, or only emit it on failure, OR use a dedicated stream the wrapper can selectively filter. Found by silent-fail sweep agent.
