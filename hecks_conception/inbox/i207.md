# i207 — given-failed-not-a-real-dispatch-failure

given-failed-not-a-real-dispatch-failure — Daemon error log filling up with 'GivenFailed' results from mindstream's fan-out pattern (it dispatches ALL 8 sleep-advance commands per tick ; only the matching given fires, the others guard-skip via given clauses). The dispatch wrapper treats non-zero exit as failure and tags every guard-failed dispatch as 'dispatch failed: Consciousness.X'. This drowns real failures (AggregateNotFound, SchemaError, LifecycleViolation) in expected gating noise. Two fix paths : (a) runtime returns 0 on GivenFailed (since the command was 'processed', just chose no-op) ; (b) shell wrapper inspects stderr for 'GivenFailed' and treats it as success. (a) is cleaner — guards are part of the command's contract, not a failure mode. Found 2026-05-02 during full-cycle sleep test.
