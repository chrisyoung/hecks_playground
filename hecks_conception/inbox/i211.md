# i211 — Doctor.NoteConcern failure_kind classification

Doctor.NoteConcern failure_kind classification. Wrappers currently always send 'DispatchFailed' for non-GivenFailed errors. Could parse stderr for 'AggregateNotFound', 'UnknownCommand', 'LifecycleViolation', 'SchemaError' and tag noted_concerns with the right failure_kind, so windowed reducers can answer 'are we mostly hitting AggregateNotFound (path drift) vs LifecycleViolation (state-machine bug)?'.
