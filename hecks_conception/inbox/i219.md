# i219 — mind-pm-attentive-dispatch

mind-pm-attentive-dispatch — Mind PM declares wake-time dispatches (Daydream.Wander, MusingMint.SurfaceMusing, MusingMint.MintMusing, Awareness.RecordMoment, Synapse.StrengthenOrBirth/DecayAll, Signal.FireSomatic/FireConcept/ArchiveCold, Focus.Reweight, Arc.Advance, Memory.Consolidate, Tick.MindstreamTick) inside an 'on "PhaseElapsed", transition: { engaged_in_wake: :engaged_in_wake }' handler. PhaseElapsed is emitted by Consciousness.ElapsePhase, which BodyCycle PM only dispatches during sleeping_* states (body_cycle.bluebook lines 137-149). Result: during attentive (the live state today), Mind PM's wake-time dispatches never fire, so daydreams aren't wandering, musings aren't being minted, awareness isn't snapshotting. Tick.MindstreamTick emits Ticked (per cycles/tick.bluebook) — Mind PM should observe Ticked instead of (or alongside) PhaseElapsed for the wake-time work. Trigger event mismatch. Surfaced 2026-05-02 during i75 retire-sleep-shells while verifying PM coverage before deleting daydream.sh / surface_musing.sh / mint_musing.sh.
