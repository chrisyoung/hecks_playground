# i229 — i229 rand-below-modulo-gate-in-givens

i229 rand-below-modulo-gate-in-givens — DSL primitive : givens carrying randomness or per-tick modulo gates. Examples : given { rand_below(300) == 0 } (1-in-300 stochastic) ; given { tick.modulo(60) == 0 } (every 60th tick). Used to express MintMusing per-5min cadence, Memory.Consolidate every-60-tick, similar legacy shell-side gates. Today the bluebook DSL only supports static given conditions on aggregate state. Surfaced 2026-05-03 during runaway-counter diagnosis.
