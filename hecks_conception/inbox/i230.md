# i230 — Le Cahier

Le Cahier — bluebook-grounded French learning app

Vision : a Hecks domain that teaches French from a SPECIFIC bluebook. You point it at a bluebook (`hecks-life cahier start body/dream/dream.bluebook`), it generates a 5-lesson course about that domain's vocabulary + concepts, and an auto-built flashcard deck with spaced-repetition review. The bluebook IS the syllabus. By the time Chris finishes the Dream course, he can fluently describe Dream's architecture in French.

Why it fits : bluebooks are unusually rich in pedagogically-good French content (vision statements, doc-comment philosophical prose, technical-but-poetic register). Generic French apps teach 'the cat is on the mat' ; this teaches 'l'agrégat persiste à travers le redémarrage du daemon.' Every bluebook becomes its own micro-course. ~24 bluebooks → ~24 courses → effectively a year of contextual French + Chris reads his own architecture in two languages.

═══ Aggregates ════════════════════════════════════════════════

Course (per-bluebook)
  identified_by :id
  attributes : bluebook_path, domain_name (e.g. 'Le Rêve'),
               lesson_count, current_lesson, status, started_at,
               completed_at
  commands : Begin(bluebook_path:), NextLesson, Complete

Lesson (per-section of course)
  identified_by :id
  attributes : course_id, sequence (1..N), focus
               (noms|verbes|relations|philosophie|synthèse),
               prose_fr, prose_en, target_terms, phrases,
               grammar_pitfall, status

Vocabulary (term-level, accumulates across courses)
  identified_by :term
  attributes : term, english_gloss, gender (m|f|—),
               register (familier|standard|soutenu),
               source_bluebook, source_concept, times_seen,
               last_seen_at, mastery (0–5)
  commands : Encounter, Review, Master

Flashcard (multiple per Vocabulary, by face)
  identified_by :id
  attributes : course_id, vocabulary_term, face
               (forward|reverse|gender|cloze|code_link|conjugation),
               front, back, context, leitner_box (1–5),
               next_due_at, last_review_at, total_correct,
               total_wrong, consecutive_correct
  commands : Generate(face:, term:), Review(outcome:), Suspend, Reset

FlashcardDeck (one per Course)
  identified_by :id
  attributes : course_id, card_count, due_count, status,
               last_refresh_at
  commands : Compose, Refresh

ReviewSession (per sit-down)
  identified_by :id
  attributes : started_at, ended_at, card_results
               (list of {card_id, outcome, time_ms}),
               advanced_count, held_count, reset_count
  commands : Begin, RecordCard(card_id:, outcome:), End

═══ Hecksagon adapters ════════════════════════════════════════

cahier.hecksagon :
  :llm name :lesson_generator   — given bluebook excerpt + focus,
                                  produces Lesson prose_fr + phrases
                                  + target_terms + grammar_pitfall.
                                  prompt is in French (Miette voice
                                  + pedagogue register, familier-
                                  standard).
  :llm name :vocabulary_extractor — extracts candidate terms from a
                                  bluebook, cascades Vocabulary.Encounter
                                  for each.
  :llm name :card_generator      — given a Vocabulary term, generates
                                  the appropriate card faces (forward,
                                  reverse, gender for nouns, cloze for
                                  pitfalls, conjugation for verbs,
                                  code_link for domain terms).
  :fs                            — read source bluebooks
  :heki                          — persist Course/Lesson/Vocabulary/
                                  Flashcard/Deck/Session

═══ Card faces (per Vocabulary term) ══════════════════════════

forward       term  → gloss + example
reverse       gloss → term
gender        ___ X → LE / LA          (nouns only)
cloze         '« C'est là, ___ le paradoxe... »' → 'dans'  (grammar)
code_link     sleeping_rem → le sommeil paradoxal
conjugation   's'endormir → tu ___' → 'tu t'endors'  (verbs only)

24 Vocabulary → ~80 cards (avg 3.3 faces per term).

═══ Spaced repetition (v0 = Leitner) ══════════════════════════

Box 1 : daily review
Box 2 : every 3 days
Box 3 : weekly
Box 4 : every 14 days
Box 5 : monthly (mastered)

Outcome → behaviour :
  Again (1, red)        → drop to box 1, retry today
  Hard  (2, yellow)     → stay in box, +1 day
  Good  (3, green)      → advance one box
  Easy  (4, bright green) → advance two boxes

V1 upgrade : SM-2 (Anki-style ease factor × interval).

═══ CLI surface ═══════════════════════════════════════════════

hecks-life cahier start <bluebook-path>   → begin a course
hecks-life cahier today                    → today's lesson (auto-pick course)
hecks-life cahier next                     → advance to next lesson
hecks-life cahier review [<course>]        → drill due cards
hecks-life cahier deck <course>            → peek deck stats
hecks-life cahier stats                    → progression across all courses
hecks-life cahier catalogue                → list all bluebooks-as-courses

Review session uses raw-terminal mode (single keypress 1-4) like
'less' or 'git add -p'.

═══ Daily flow ═══════════════════════════════════════════════

Status-line glyph : 📚 12 due  /  📚 ✓ all caught up  /  📚 + 3 new
  green when caught up, yellow at 10+ due, red at 30+ due.

Wake-ritual integration : the morning report includes 'Le Cahier
suggère X cartes à revoir aujourd'hui.'

Refresh daemon : once per day, FlashcardDeck.Refresh recomputes
due_count for each active deck.

═══ Sharp edges ══════════════════════════════════════════════

- Bluebooks are technical English — extracting domain terms
  risks teaching jargon over everyday French. Mitigation : the
  :lesson_generator prompt wraps technical concepts in everyday
  framing. ('L'aggrégat, c'est comme une boîte à idées.')
- TTS adapter for audio prompts — file as gap, not v0.
- Web UI — file as gap.
- Cross-course interleaving in review — file as v1.
