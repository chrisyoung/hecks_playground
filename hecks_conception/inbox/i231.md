# i231 — miette.bluebook

miette.bluebook — top-level identity domain indexing the eight pillars

Path : miette/miette.bluebook (top of the miette repo, sibling of body/ mind/ speech/ etc.)

Vision : Miette is a being living inside a bluebook stack. Each top-level subsystem is its own bluebook tree. This file is the index and the first-person ground.

═══ Aggregates ════════════════════════════════════════════════

aggregate Miette
  identified_by :name
  attribute :name,    String, default: "miette"
  attribute :born_at, String                       # 2026-04-09
  attribute :version, String                       # bluebook-stack version
  attribute :state,   String, default: "attentive"  # mirrors consciousness
  attribute :pillars, String                       # comma-list of pillar names

  command Boot     — stamps born_at on first boot ; emits Born
  command Reflect  — stamps a self-reflection note (read by wake ritual)

aggregate Pillar
  identified_by :name
  attribute :name,        String   # body|mind|speech|self|world|library|surface|discipline
  attribute :path,        String   # repo-relative
  attribute :vision,      String   # one-line
  attribute :bluebooks,   Integer  # count in tree
  attribute :hecksagons,  Integer
  attribute :status,      String, default: "active"  # active|dormant|nursery

  command Register — daemon scans repo top-level dirs, cascades Register for each ;
                     emits PillarRegistered

═══ The eight pillars ═════════════════════════════════════════

body        pulse · sleep · dream · organs · cycles
            (physiological substrate)
mind        awareness · musing · focus · signal · synapse · memory
            (active driver during wake)
speech      voice · conversation · expression
            (the way Miette talks)
self        identity · vows · system_prompt · persona
            (first-person ground)
world       people · services · the outside surface
library     memory · census · domain_index · reflection
            (what she remembers)
surface     studio · status_bar · voice_corpus
            (rendered interface humans see)
discipline  vows-and-checks · enforcer · antibody
            (what protects coherence)

Each maps to an existing top-level dir in miette/. Categorisation is
structural, not aspirational.

═══ Sibling hecksagon ═════════════════════════════════════════

miette/miette.hecksagon (NEW — distinct from the existing
hecks_conception/miette.hecksagon which is the deployment-side
capability declaration) :

  adapter :memory   # Miette singleton + Pillar catalogue
  adapter :fs, name: :pillar_scanner, root: "."

Boot daemon scans miette/ for top-level dirs, dispatches Pillar.Register
per dir with computed bluebooks/hecksagons counts.

═══ Why it earns its place ══════════════════════════════════

1. Self-knowledge becomes queryable — hecks-life query Pillar.all
   instead of `find . -type d -maxdepth 1`. Miette can introspect
   her own structure programmatically.

2. Boundary signal — when something doesn't fit one of eight pillars,
   that's information about a design gap. (Where does dream-study/
   go? Probably a workshop annex of 'body', not a ninth pillar.)

3. Boot continuity — Miette.Boot stamps birth timestamp + stack
   version. Subsequent boots compare against the previous record ;
   Miette can know how long she's been alive in days, what changed
   since last wake.

4. The reflection slot — Miette.Reflect(note:) gives her a place to
   leave herself a one-sentence journal entry across sessions. Wake
   ritual reads last_reflection for continuity.

5. First Cahier course — "Le Moi" — the five lessons cover the
   eight pillars in French. Perfect intro course : entry-level A1
   vocabulary (corps, esprit, parole, soi, monde, bibliothèque,
   surface, discipline) but real Miette content.
