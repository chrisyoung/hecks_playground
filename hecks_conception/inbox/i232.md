# i232 — :fs adapter family

:fs adapter family — first-class file-system side-effect adapter for atomic writes

Sibling of :llm and :compute (PR #597). New adapter family with shape :
  adapter :fs, name: :wake_review_artefact do
    function :atomic_write
    trigger_on "WakeReview.LockReport"
    path "/tmp/wake_review_latest.md"
    payload_attr :report_markdown
  end

Runtime resolver mirrors resolve_compute_adapters / resolve_llm_adapters.
Provider invokes atomic write : write to <path>.tmp.<pid>, mv -f to <path>.

Closes the wake_review.sh retirement gap : with :fs adapter, LockReport
gains a side-effect that writes report_markdown to /tmp/wake_review_latest.md,
and body/wake_review.sh deletes entirely.

Same 13-touchpoint walk as :compute (PR #597) :
  1. Rust IR struct (FsAdapter in hecksagon_ir.rs)
  2. Rust parser (parse_fs_adapter in hecksagon_parser.rs)
  3. Parser snippet for specializer
  4. Parser fixture doc_comment
  5. Runtime resolver (resolve_fs_adapters_with_excluded)
  6. Runtime snippet for specializer
  7. Ruby IR (FsAdapter struct in hecksagon/structure)
  8. Ruby DSL builder (fs_adapter_builder.rb)
  9. Ruby canonical dump (dump_fs_adapter in canonical_ir.rb)
 10. Rust canonical dump in main.rs
 11. cli_dispatch snippet for canonical dump
 12. Test struct literals (rust/tests/fs_dispatcher_test.rs)
 13. Miette consumer (wake_review.hecksagon LockReport :fs binding)

Defer until i220 wake-review compute-function PR lands. Same retirement
contract as :compute : retires when adapter family becomes bluebook-driven
via dedicated dispatcher bluebook.
