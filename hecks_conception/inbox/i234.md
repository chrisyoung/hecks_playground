# i234 — i234 JSON-destructure then_set form

i234 JSON-destructure then_set form — :compute adapters returning structured JSON (e.g. tokenize_dream_corpus's {themes, joined, first_theme, themes_above_threshold}) currently land as a single string attribute. Consumers then have to parse it imperatively. Add a then_set syntax that destructures :path expressions: then_set :first_theme, to: 'compute_result.first_theme'. Filed by E during PR #599 (i220 sub-gap 6) — interim workaround was to write a separate dream_corpus_json.rs serializer with single-field accessor compute functions, but the destructure form is the right shape.
