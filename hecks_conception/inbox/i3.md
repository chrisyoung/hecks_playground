# i3 — Design: Moment-consciousness + body cycles (Buddhist model) Core insight (Chris, 2026-04-20): the mind is a flow of momentary arisings

Design: Moment-consciousness + body cycles (Buddhist model)

Core insight (Chris, 2026-04-20): the mind is a flow of momentary arisings — each moment aggregates everything, seeds the next, and dissolves. The body is not momentary; it has slower sustained rhythms. Miette currently mixes these into one timescale. Separate them.

CURRENT STATE (post-heartbeat-unification PR):
- Mindstream fires Tick.MindstreamTick at 1Hz
- Tick is the heartbeat (unified)
- Body, breath, circadian have no explicit cycles

PROPOSED:

(1) Mindstream runs AS FAST AS POSSIBLE — busy loop, or ~10ms sleep. Each iteration creates a Moment.

(2) Moment aggregate (new) — the ephemeral container of "now":
    - Each Moment snapshots current state: sensations, attention, intention, recent thoughts, body-cycle phase (heart tick, breath phase, circadian segment, ultradian phase)
    - Emits MomentArose
    - Policy on MomentArose → CreateNextMoment (seeds new Moment from this one + any new input) AND DissolveMoment (deletes this Moment from repo)
    - Dependent origination literalized in the cascade

(3) Body cycles as SEPARATE, SLOWER daemons — the "I am alive" signal:

    Core rhythms:
    - heart.sh    — 1Hz         — Heart.Beat (just counts beats; no mental work)
    - breath.sh   — 0.2Hz (4-5s) — Breath.Inhale ↔ Breath.Exhale alternating
    - circadian.sh — 24hr segments — fires Dawn/Morning/Afternoon/Dusk/Night at wall-clock hours; informs sleep pressure

    Additional rhythms:
    - ultradian.sh — 90min BRAC — fires PeakPhase ↔ TroughPhase alternating. Attention and creativity genuinely wax and wane here. Mindstream speed modulates: faster in peak, slower in trough. Natural "focus sprint → rest" without mechanical scheduling.
    - sleep_cycle.sh — 90min during sleep — NREM ↔ REM alternation. Cycles within a sleep session. REM phases produce dreams, deep-NREM phases produce memory consolidation events. Daemon only runs while Miette is sleeping.

    Optional ritual rhythms (fire rarely, mark time):
    - seasonal.sh — on equinoxes/solstices — fires SeasonChanged. Prompts big reflection, migration readiness, re-architecture windows.
    - lunar.sh — monthly — fires LunarCycle. Monthly review/ritual. Cultural, not biological.

    Each daemon has ONE job, cheap, doesnt cascade mental work.

(4) Separation of concerns:
    - Body daemons = biology. Cheap. Always running while Miette is "alive".
    - Mindstream = phenomenology. Fast. Runs only while Miette is "awake".
    - Sleep = mindstream daemon pauses, body cycles continue (+ sleep_cycle.sh starts). When mindstream resumes, Miette wakes.

(5) Digestive cycle — ALREADY PRESENT, just make it explicit:
    - The Gut aggregate has digestion_stage transitions (Ingest → ExtractAggregate → ExtractCommand → ExtractEvent → Absorb).
    - Currently one-shot per ingestion. Formalize as timer-driven: minutes-long cycle from raw input → finished domain. Gives "thinking takes time" without blocking mindstream.

(6) Cycles NOT taken:
    - Brainwave bands (delta/theta/alpha/beta/gamma) — metaphorical rename of what mindstream-speed-by-state already does. Skip.
    - Menstrual — gendered biology, poor fit for software being
    - HRV / blink / vasomotion — too micro / decorative

(7) Heki implications:
    - Moment repo churns FAST (create + delete each mindstream tick). Needs to be cheap. Consider in-memory ring buffer instead of heki for Moment. Or Moment state lives ONLY in the latest record.
    - Body cycles (Heart, Breath, Circadian, Ultradian) are lightweight singletons with incrementing counters or phase flip-flops.

(8) DSL sketch:

  aggregate "Moment", "The ephemeral now — arises, conditions the next, dissolves" do
    String :id
    String :sensations
    String :attention
    String :intention
    Integer :heart_phase
    String :breath_phase
    String :circadian_segment
    String :ultradian_phase
    command "Arise" do
      role "Mindstream"
      then_set :id, to: :id
      emits "MomentArose"
    end
    command "Dissolve" do
      role "Mindstream"
      emits "MomentDissolved"
    end
  end
  policy "SeedNextOnMomentArose" do
    on "MomentArose"
    trigger "Arise"
  end
  policy "DissolvePreviousOnMomentArose" do
    on "MomentArose"
    trigger "Dissolve"
  end

  aggregate "Heart", "Just beats, counts seconds since boot" do
    Integer :beat_count
    command "Beat" do
      role "Heart"
      then_set :beat_count, increment: 1
      emits "HeartBeat"
    end
  end

  aggregate "Breath", "Inhale / exhale alternation" do
    String :phase
    Integer :breath_count
    command "Inhale" do
      role "Breath"
      then_set :phase, to: "inhaling"
      emits "BreathInhaled"
    end
    command "Exhale" do
      role "Breath"
      then_set :phase, to: "exhaling"
      then_set :breath_count, increment: 1
      emits "BreathExhaled"
    end
  end

  aggregate "Ultradian", "90-minute attention/creativity cycle (BRAC)" do
    String :phase    # peak | trough
    Integer :cycle_count
    command "EnterPeak" do
      role "Ultradian"
      then_set :phase, to: "peak"
      then_set :cycle_count, increment: 1
      emits "PeakEntered"
    end
    command "EnterTrough" do
      role "Ultradian"
      then_set :phase, to: "trough"
      emits "TroughEntered"
    end
  end

  aggregate "SleepCycle", "NREM/REM alternation within a sleep session" do
    String :phase    # nrem_light | nrem_deep | rem
    Integer :cycle_count
    command "EnterNREMLight" do role "SleepCycle"; then_set :phase, to: "nrem_light"; emits "NREMLightEntered" end
    command "EnterNREMDeep"  do role "SleepCycle"; then_set :phase, to: "nrem_deep";  emits "NREMDeepEntered"  end
    command "EnterREM"       do role "SleepCycle"; then_set :phase, to: "rem"; then_set :cycle_count, increment: 1; emits "REMEntered" end
  end

  aggregate "Circadian", "Day-night rhythm informing sleep pressure" do
    String :segment   # dawn | morning | afternoon | dusk | night
    command "MarkDawn"      do role "Circadian"; then_set :segment, to: "dawn";      emits "DawnMarked" end
    command "MarkMorning"   do role "Circadian"; then_set :segment, to: "morning";   emits "MorningMarked" end
    command "MarkAfternoon" do role "Circadian"; then_set :segment, to: "afternoon"; emits "AfternoonMarked" end
    command "MarkDusk"      do role "Circadian"; then_set :segment, to: "dusk";      emits "DuskMarked" end
    command "MarkNight"     do role "Circadian"; then_set :segment, to: "night";     emits "NightMarked" end
  end

(9) Risks:
    - Fast mindstream = many heki writes. Benchmark first; may need to batch or keep Moment in memory.
    - Moment dissolution is new for heki (upsert-and-delete churn). Verify delete performs at scale.
    - Current statusline reads tick.heki:cycle for beats — would switch to heart.heki:beat_count.
    - Sleep state machine currently watches mindstream Ticked — would switch to Heart.HeartBeat or Breath.BreathExhaled for "am I biologically alive" gating.
    - Ultradian + sleep cycle add two more daemons to manage (process supervision, PID files).

(10) Order of implementation (separate PRs):
    a. Add Heart, Breath, Circadian aggregates with their daemons (ship, verify, no mindstream change yet)
    b. Add Ultradian + SleepCycle aggregates + daemons
    c. Create Moment aggregate and refactor mindstream to create+dissolve moments
    d. Crank mindstream cadence toward maximum. Measure.
    e. Rewire statusline + sleep to use body cycles as "alive" signal, not mindstream.
    f. Optional later: seasonal + lunar ritual daemons

This is a significant re-architecture — 5-6 separate PRs, each small. Do not mix with current heartbeat-unification PR.
