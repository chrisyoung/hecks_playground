# i370 — Design: pre-seed Hecks domains from curated web ontologies (schema.org, Wikidata, industry standards). Core insight (Chr

Design: pre-seed Hecks domains from curated web ontologies (schema.org, Wikidata, industry standards). Core insight (Chris, 2026-04-20): schema.org is a 15-year-curated shared vocabulary (Google/Microsoft/Yahoo/Yandex) with thousands of types and ~30K properties. Entities map cleanly to Hecks — types (Product, Event, Order, MedicalCondition) → aggregates; properties → attributes; relationships → references; state enums (OrderPickupAvailable, OrderShipped, OrderDelivered) → lifecycles; Action subtypes (BuyAction, PayAction, ReviewAction) → commands. Consuming this ontology means standing on 15 years of shared-vocabulary work instead of reinventing per project. Commands to reify: IngestSchemaOrg (fetch JSON-LD definitions), ConceiveFromSchemaType (type → aggregate with attributes/refs/lifecycle), InferCommandsFromActions (Action subtypes → commands on related aggregates), ExtractUL (property names → ubiquitous language seed). Other tagging corpora worth wiring: Wikidata / DBpedia (richer, SPARQL queryable, powers Google Knowledge Graph); Google Product Taxonomy (retail hierarchy); FHIR (healthcare); GS1 (supply chain); ISO 20022 (finance); Google Dataset Search metadata; Common Crawl schema.org extractions (real-world usage at scale). Strategic angle for Embryonaut: pre-seeded onboarding — 'tell us your industry, we conceive 50 domains schema.org + Wikidata say you need'. A retailer gets Product, Order, Customer, Review, Shipment, Return as bluebooks before writing a line. The 10-minute 'stick the landing' UX. Follow-up: prototype IngestSchemaOrg on the Product type end-to-end, see how close the generated bluebook is to hand-written. If ≥ 70% the commercial pitch writes itself.
