# i380 — Ruby DSL bug surfaced after Float/Integer shorthand fix: ImplicitSyntax misroutes PascalCase `do` blocks. Inside an aggr

Ruby DSL bug surfaced after Float/Integer shorthand fix: ImplicitSyntax misroutes PascalCase `do` blocks. Inside an aggregate, `SetupTank do ... end` should be a command, but ImplicitSyntax routes it to `value_object` first because both match PascalCase. This was hidden behind the Float crash. Fix would disambiguate: a do-block with `reference_to`, `given`, `then_set`, `emits` is a command; a do-block with only attributes is a value_object. 302 nursery bluebooks still fail to load in Ruby for this reason. Rust parser handles them all correctly (parity 215/215 holds).
