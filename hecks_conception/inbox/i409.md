# i409 — port-shell-scripts-to-bluebook — Sibling of i62 delete-dead-rust. The repo has many shell scripts under hecks_conception

port-shell-scripts-to-bluebook — Sibling of i62 delete-dead-rust. The repo has many shell scripts under hecks_conception/ that are adapter implementations of declared bluebook domains: rem_branch.sh (RemDream), wake_report.sh (WakeReport), interpret_dream.sh, inbox.sh, boot_miette.sh, mindstream.sh, heart.sh, breath.sh, sleep_cycle.sh, statusline-command.sh, pulse_organs.sh, daydream.sh, circadian.sh, ultradian.sh, consolidate.sh, mint_musing.sh, surface_musing.sh, shutdown_miette.sh, status.sh, status_coherence.sh, test_miette.sh. Each is carrying logic that either belongs in a declared bluebook + hecksagon (driven by runtime) or in kernel-floor Rust (irreducible primitive). Already in-flight: i44 statusline-as-bluebook. Every shell-retirement PR must either ship runtime wiring that replaces the shell end-to-end OR explicitly justify why a given script is kernel-floor (e.g. mindstream's sub-second tick loop may be one). Pattern-matches delete-dead-rust: declaration without deletion is not enough — deletion is the close of the loop.
