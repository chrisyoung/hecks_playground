# i423 — hecks-life-loop-multi-command-extension — i76's loop primitive dispatches ONE command at cadence. The body daemons that

hecks-life-loop-multi-command-extension — i76's loop primitive dispatches ONE command at cadence. The body daemons that aren't heart-shaped need more : breath.sh alternates Inhale/Exhale at 4.5s, ultradian.sh alternates EnterPeak/EnterTrough, circadian.sh has time-of-day branching (dawn/morning/afternoon/dusk/night). Three extension shapes worth considering : (a) 'hecks-life loop' takes a comma-separated command list and rotates through them ; (b) a sequence-loop primitive like 'hecks-life sequence agg/ Inhale,Exhale --every 4.5s' ; (c) the bluebook itself declares the alternation via a Cycle aggregate with multiple commands and an internal state machine, then 'hecks-life loop' dispatches a single 'TickCycle' that advances the state. Option (c) is the most bluebook-native — keeps the alternation logic IN the bluebook where it belongs. Acceptance : breath.sh / ultradian.sh / circadian.sh retire alongside heart.sh, replaced by single 'hecks-life loop' invocations driving bluebook-internal state machines that handle the alternation. This is part of the i75 sweep but specifically the 'multi-step daemons' subset.
