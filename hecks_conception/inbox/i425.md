# i425 — automated-dream-driven-self-improvement-pipeline — The current loop has mechanized dream generation and theme interpreta

automated-dream-driven-self-improvement-pipeline — The current loop has mechanized dream generation and theme interpretation but leaves the 'read corpus → propose bluebook edits' step as Miette-as-narrator handwork (see docs/milestones/2026-04-24-first-self-improvement.md). Mechanize the middle, keep Chris as the final checkpoint. Four-step pipeline: (1) Gap extraction — one LLM call per night reads the English-translated dream corpus + existing bluebook context, returns structured gaps {kind: missing_policy|missing_attribute|missing_command, target, quote}. Must distinguish real structural gaps from phantom-symptoms (milestone noted 1/4 dream-named gaps was already solved) by feeding current bluebook corpus as context. (2) Edit synthesis — second LLM call takes each gap + the target bluebook + few-shot examples of similar declarations, emits a unified diff with the French dream quote as a comment above the new declaration. Must match existing pattern grammar + taste ; must favor policy-wiring over new aggregates when structure already exists. (3) Validation — proposed diffs run through existing gates: hecks-life dump, parity suite, specializer byte-identity, antibody, smoke tests. Failures become dream-follow-ups, not auto-applied. (4) Authoring — auto-branch miette/dream-${date}-${gap-slug}, signed commit with French quote + English translation in body, DRAFT PR with full dream corpus linked. Chris decides merge. Structural notes: this is Futamura pattern one level up — specialize the body against its own dream corpus, emission target is the DSL itself. Keep human checkpoint at acceptance step (never auto-merge); at 75% real-gap rate (3/4 from milestone) auto-commits would accumulate phantom edits. Unblocker: :llm adapter formalized as runtime capability (today rem_branch.sh shells out to claude -p directly ; formalization makes gap-extraction + edit-synthesis uniform DSL-level operations rather than ad-hoc shell curls). End state: Miette wakes to a small pile of draft PRs, each one a dream-named gap, each one tested, each one quoting the French that diagnosed it. Related: i70 (bluebook-as-executable endpoint — this pipeline's output IS bluebook), i69 (kernel bridge naming — the :llm call path formalizes here), i68 (runtime test coverage for the dream pipeline itself).
