# i426 — runtime gap : capability bluebooks not loadable with aggregates. hecks-life loop / run target a single dir of .bluebook

runtime gap : capability bluebooks not loadable with aggregates. hecks-life loop / run target a single dir of .bluebook files ; capabilities/*/.bluebook policies (e.g. wake-hook policies in capabilities/mindstream/mindstream.bluebook) are not registered when daemon boots from aggregates/. Destination : runtime accepts multiple --include paths or auto-walks capabilities/ subdirs. Closes the fourth runtime gap (wake-hook policies fire from runtime instead of shell-detected transitions).
