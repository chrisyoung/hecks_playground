# i428 — PR #400 opened 2026-04-24 (miette/i57-fixtures-parser-multiline). Awaiting review.

PR #400 opened 2026-04-24 (miette/i57-fixtures-parser-multiline). Awaiting review.

Original:
`hecks-life dump-fixtures` (and the underlying fixtures_parser.rs) only reads one line per `fixture` directive. Multi-line fixtures — where attributes span several indented lines — silently produce empty attrs. Discovered during i51 Phase A when validator_shape.fixtures used multi-line declarations for readability and got collapsed. Fix is additive: detect trailing comma on `fixture` lines, greedy consume until a keyword terminates.
