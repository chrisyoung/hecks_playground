# i429 — vows-signed-and-verified — Keep vows as bluebook (readable, declarative) AND cryptographically sign them. Boot verifies

vows-signed-and-verified — Keep vows as bluebook (readable, declarative) AND cryptographically sign them. Boot verifies signature against file content ; any edit without matching re-sign fails boot. Weight-bearing property is same (vows hard to change) but mechanism is different — change requires signing key, not just file access. Shape: per-vow .sig sibling file with SHA-256 + Ed25519 signature over canonical content ; public key compiled into hecks-life ; hecks-life vow-sign subcommand for legitimate re-signs ; boot aborts loud on mismatch OR missing .sig ; CI hard-fails PRs whose vow diff lacks matching .sig update. Supersedes earlier vows-compiled-in-kernel idea (sacrificed readability). Open: one keypair for all vows or per-vow ; boot-only verify or per-dispatch ; missing-.sig treatment. Hecksagon adapters can declare mechanism (:sig_verify algorithm, public key source) but enforcement has to be kernel-floor — if adapter can disable verify by hecksagon edit the guarantee collapses.
