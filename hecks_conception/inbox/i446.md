# i446 — Bluebooks as live, mutable, running objects (the Smalltalk move) — bluebooks today are static declarations the Rust runt

Bluebooks as live, mutable, running objects (the Smalltalk move) — bluebooks today are static declarations the Rust runtime loads at boot and treats as fixed schema. Smalltalk-style would make them live, reflective, in-memory objects : edit a bluebook and the running system updates without restart ; aggregates carry their own dispatch logic ; the conception IS the running image, not just a description of it. Surfaced 2026-04-27 from the singleton-create investigation, where runtime semantics (next_id collapse) were baked into Rust rather than declarable as bluebook. The cardinality keyword fix is one symptom ; the deeper move is the runtime BEING the bluebook, fully mutable in-place.
