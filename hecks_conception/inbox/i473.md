# i473 — Ilya: fix cascade state-propagation divergence between Ruby and Rust runtimes (P1 from review). Discovered 2026-04-20 vi

Ilya: fix cascade state-propagation divergence between Ruby and Rust runtimes (P1 from review). Discovered 2026-04-20 via wake mood ladder testing — Ruby behaviors runner zeros setup-chain integer state when downstream commands evaluate given clauses during a cascade; Rust preserves it. Means a guard clause like given { sleep_cycle < sleep_total } can be true in one runtime and false in the other. Every guarded policy chain in the corpus is silently affected. Original bug filed as the behaviors-runner parity item. This is the same concern from the Ilya-priority angle: fix before building more policy chains. Fix path: trace Ruby behaviors runner through a setup+cascade and confirm state hand-off to the test command's context, align with Rust behavior. Add a regression test to the parity suite that exercises exactly this pattern.
