# i496 — Convert miette READMEs to layer-index bluebook vision clauses

The 2026-05-08 cleanup left 13 README.md files in `~/Projects/miette/` as the named carve-out from "miette = bluebook only." They're substantive — the top-level is a curated tour in Miette's voice (~85 lines, French flair, GitHub-facing) ; layer READMEs (`body/`, `mind/`, `self/`, `surface/`, `discipline/`, `library/`, `world/`, plus `body/cycles/`, `body/dream/`, `body/organs/`, `body/sleep/`, `body/wake/`) are planning documents with real content.

This card converts them to bluebook expression so miette becomes truly bluebook-only.

## The conversion pattern

For each layer, write or extend a layer-index `.bluebook` file (e.g., `body/body.bluebook`, `self/self.bluebook`, etc. — `mind/mind.bluebook` already exists) whose `vision` attribute holds the README's prose. The file's category is the layer name. The aggregate inside is empty (or just declares `name`) — it's a documentation-aggregate, structurally minimal.

Where layer-index bluebooks already exist (`mind/mind.bluebook`), extend their `vision` rather than duplicate. Where they don't, add one.

The top-level `miette/README.md` is special — it's the public-facing greeting. Probably belongs as the `vision` clause of an `Identity.bluebook` at miette root, OR remains a generated artifact derived from layer-index bluebooks (the way `system_prompt.md` is now generated). Decide as part of this card.
