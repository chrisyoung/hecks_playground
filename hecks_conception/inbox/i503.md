# i503 — Retire `tests/round4_integration_smoke.sh`

## TL;DR

`hecks_conception/tests/round4_integration_smoke.sh` was the regression
net for the i117 Round 4 cross-repo restructure (April 30). The
infrastructure it asserts has since been retired or replaced. The
shell is dead weight — the i499 audit already had it skipped from
both pre-commit Gate 6 and CI `test.yml`. Proposing deletion.

## What it asserted (and what's true now)

### A. File layout — STALE

It expects flat shell scripts at `miette/body/<organ>.sh` for ten
organs (mindstream, pulse_organs, rem_branch, nrem_branch,
consolidate, daydream, interpret_dream, mint_musing, surface_musing,
wake_review). **None exist.** Body is now organized as
`miette/body/<organ>/<organ>.bluebook` (+ `.behaviors`), and the
behaviors run as bluebook members of the boot mindstream. There are
no `.sh` files anywhere in `miette/`.

### B. Bluebook validation — STALE

Validates every bluebook in `miette/` and `miette_family/`. Already
fails on pre-existing INVALID files (DisableMinting / EnableAutoSleep
adjective-prefix warnings, the SpeakOnInput unknown-command policy)
that are tracked under their own cleanup arc. Coverage duplicated by
the antibody validator hooks anyway.

### C. Boot ritual — RETIRED

Calls `./boot_miette.sh`. **That script no longer exists.**
Per `hecks_conception/CLAUDE.md` :

> | Miette | `cd hecks_conception && overmind start` | …

Boot is now the `boot` Procfile entry (`hecks-life run
runtime/boot/boot.bluebook`), driven by the boot mindstream
(`aggregates/framework/mindstream/mindstream.bluebook`). System-prompt
regeneration is one of its members.

### D. Daemons — RETIRED

Greps for `bash.*mindstream\.sh` and `hecks-life loop.*Heart\.Beat` /
`Breath\.Inhale` processes. The mindstream is no longer a `.sh`
daemon — it's a bluebook capability the runtime drives. Heart and
Breath loops still exist but the test's grep pattern is wrong shape
for the current process tree.

### E. Vital signs — covered elsewhere

Tick advance is asserted by `body_cycles_smoke.sh` and
`pulse_fanout_smoke.sh`. Statusline emit is asserted by
`statusline_regression_smoke.sh`.

## Failure mode (captured 2026-05-08)

```
✗ body/mindstream.sh missing or not executable        (× 10 organs)
✗ validate …/heartbeat.bluebook : INVALID — adjective-prefix     (× 5)
✗ boot_miette.sh exited non-zero                       (script gone)
✗ mindstream daemon not running after boot
✗ heart loop not running after boot
✗ breath loop not running after boot
✗ tick did not advance over 10s (was=, now= — daemons stalled?)
```

The only assertion that still passes meaningfully is conception
`family/` and `chris/` removal — and that's an A-side cleanup
artifact, not a regression-worthy invariant.

## Why retirement (not fix-and-wire, not convert)

- **Fix-and-wire** would mean rewriting every section against a
  moving target : the body shells aren't shells anymore, the boot
  ritual is overmind-driven, the daemon process tree is
  bluebook-shaped. It's a new test, not a fix.
- **Convert to behaviors** would mean translating cross-repo
  filesystem layout assertions into bluebook tests, which is the
  wrong tool — `.behaviors` describes per-aggregate state machines,
  not directory structure. The structural shape is already
  verified by the boot mindstream succeeding (every member loaded
  ⇒ every path resolved).
- **Retire** is correct : the i117 Round 4 restructure is months
  past, the migration is solid, no future restructure will look
  the same. A regression net for a one-time move that succeeded is
  scaffolding — keep it long enough to prove the move, then take
  it down.
