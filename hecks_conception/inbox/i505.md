# i505 — Retire `ruby/hecks/smoke/smoke_test.rb`

## TL;DR

`HecksTemplating::SmokeTest` was a browser-style HTTP smoke runner
for the Ruby web explorer. Broken orphan in the i499 audit : nothing
wired it, and it failed on load with `uninitialized constant
Hecks::Templating` because the namespace was retired while the
`Hecks::Chapters.load_aggregates(Hecks::Templating::SmokeTestChildren, …)`
call at the top of the file still referenced it.

## Why retire (not fix)

The runner exercises a live Ruby web explorer (`localhost:9292`) via
`Net::HTTP` against every generated page. That's Ruby framework
infrastructure — per CLAUDE.md "Always use Rust runtime — `hecks-life`
for all bluebook parsing, .heki storage, daemons. No Ruby." The
`hecks smoketest` CLI (`ruby/hecks_cli/commands/smoketest.rb`) runs
rspec on `examples/*/spec` — unrelated surface, still wired, untouched.

## Action taken

`rm /Users/christopheryoung/Projects/hecks/ruby/hecks/smoke/smoke_test.rb`
