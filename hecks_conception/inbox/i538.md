# i538 — All commands per aggregate card

## Why this card exists

The walking skeleton's aggregate card today shows only the first
command (typically the creator — `Register`, `Subscribe`,
`Build`, etc.). Other commands on the same aggregate — `ChangeRole`
on Account, `Cancel` / `Complete` on AddOn, `Activate` /
`Deactivate` / `MarkGraceElapsed` on Subscription — are visible
only in the sidebar nav (where the link is broken — see i104's note
about anchors).

To exercise anything besides the creator, the user has to leave the
walking skeleton entirely and use the Living Diagram's dispatch
panel. That's two different surfaces with different ergonomics and
the user has to know to switch.

## What changes

In `html_domain.rs`, after the aggregate's name + description,
render EVERY command — not just the first. Two layout options :

1. **Stacked collapsibles.** First command (creator) open by default ;
   the rest collapsed under their command name. Click to expand.

2. **Tabs.** Command names along the top, one form below at a time.

Stacked-collapsibles is simpler and copies the sidebar's `<details>`
pattern. The creator stays prominent, the rest are accessible.

For commands that need state (e.g. `Subscription.Cancel` requires
an existing Subscription record), the form's reference picker (i537)
handles the linkage. The form just dispatches with the right id.
