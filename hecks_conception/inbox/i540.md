# i540 — Translate `RuntimeError` to human strings

## Why this card exists

Dispatch failures today return Rust `Debug` formatting of
`RuntimeError` variants :

- `UnknownCommand("FrobTheWidget")`
- `MissingAttribute("auth_identity")`
- `LifecycleViolation { command: "Cancel", required: "active", current: "draft" }`
- `InvalidValueObjectMember { field: "role", value: "banana", allowed: ["customer", "owner", ...] }`

These are debug-level. A user sees brackets and parens and quotes
and gets confused. Each variant needs a translation function that
produces a single sentence + (when applicable) a suggested fix.

## What changes

**Worker** : in `walking_skeleton_dispatch` (lib.rs), instead of
`format!("{:?}", e)`, call a new `humanize_runtime_error(&e)` that
returns a struct :

```rust
{
  message: String,        // user-facing one-liner
  suggestion: Option<String>, // what to try instead
  field: Option<String>,  // which field caused it (so the form can highlight)
}
```

The handler returns `{ok: false, error: { message, suggestion, field }}`
and the renderer's dispatch JS shows the message inline, highlights
`field` if present, and surfaces the suggestion as a hint.

## Translation table (initial pass)

| Variant | Message |
|---|---|
| `UnknownCommand(name)` | "No command named `name` on this aggregate." |
| `MissingAttribute(name)` | "The field `name` is required." (highlight field) |
| `LifecycleViolation { command, required, current }` | "Cannot run `command` from state `current` — it needs `required`." |
| `InvalidValueObjectMember { field, value, allowed }` | "`field` only allows: `allowed.join(', ')`. You sent `value`." |
| `MissingReference { field, target }` | "No `target` record matches the supplied `field` id." |
