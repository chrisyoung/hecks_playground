# i542 — Per-aggregate icons

## Why this card exists

The walking-skeleton aggregate cards and sidebar entries use an emoji
icon next to the aggregate name. Account is 👤, BinInventory 📦.
Everything else falls back to a default 📋 (clipboard). Reading the
grid is harder than it needs to be — every card looks the same at
a glance.

## What changes

Two layers :

1. **Declare icon in the bluebook.** Each aggregate's
   `Hecks.bluebook` declaration gets an optional `icon "🚛"` line.
   The renderer reads it.

2. **Fallback table** in the renderer for aggregates that don't
   declare one yet. Suggested initial assignments :

   | Aggregate | Icon |
   |---|---|
   | Account | 👤 |
   | AddOn | ➕ |
   | BinInventory | 📦 |
   | CityCalendar | 🗓️ |
   | CreditCardProcessing | 💳 |
   | Customer | 🧍 |
   | DriverApplication | 📝 |
   | Notifications | 📣 |
   | Photo | 📷 |
   | Plan | 📋 |
   | Route | 🚛 |
   | ServiceAddress | 🏠 |
   | ServiceTask | ✅ |
   | Subscription | 💰 |
   | SystemTest | 🧪 |
   | WorkerShift | ⏱️ |

The bluebook-declared icon wins ; the fallback table is just a sane
default for the framework's first-time render.
