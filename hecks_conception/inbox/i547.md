# i547 — Top-bar navigation across walking skeleton + diagram surfaces

## Why this card exists

Today's headers :

- `/` and `/domains/BinBuddy` (walking skeleton) — sidebar with
  "Bin Buddy / Dashboard" + nav rail
- `/diagram` and `/diagram/BinBuddy` (Living Diagram) — just
  "📊 BinBuddy — Living Diagram" + a "← Walking Skeleton" link

Once on the diagram, you can navigate to the walking skeleton ; once
on the walking skeleton, you can navigate to the diagram. But there's
no link to `/portal/`, no link to `/` (the home), no domain switcher
for when multiple domains exist.

## What changes

A small, persistent top-bar rendered on every framework surface :

```
[🏠 Home]  [🌌 Universe]  [📋 Walking Skeleton]  [📊 Diagram]  [🛒 Customer Portal]
                                                                    ─────────────
                                                                   Active: BinBuddy ▾
```

- `Home` → `/`
- `Universe` → `/diagram`
- `Walking Skeleton` → `/domains/<currentDomain>`
- `Diagram` → `/diagram/<currentDomain>`
- `Customer Portal` → `/portal/`
- Domain dropdown → switch between every loaded domain (today just
  BinBuddy ; future multi-domain apps light up additional entries)

The currently-active surface is highlighted. Bin-buddy-specific
links like `/portal/` are app-side overrides ; the framework
default is the first four.
