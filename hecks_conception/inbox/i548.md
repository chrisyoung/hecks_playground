# i548 — `/diagram/_all/graph.json` route

## Why this card exists

The Living Diagram's universe view (`/diagram` with `domain = "_all"`)
fetches its graph data from `/diagram/_all/graph.json`. The worker
today has only the parameterized handler at
`/diagram/:domain/graph.json` — `_all` slots into `:domain` and the
parameterized handler tries `runtimes.get("_all")` which 404s.

Hand-in-hand with i546 (universe view differentiation).

## What changes

In the worker's router :

```rust
.get("/diagram/_all/graph.json", diagram_universe_graph_json)
.get("/diagram/:domain/graph.json", diagram_graph_json)
```

The `_all` route MUST come first (or use a more specific match)
because workers-rs Router matches in declaration order.

`diagram_universe_graph_json` calls
`storehouse::server::html_diagram::all_domains_graph_json(&runtimes)`
and returns the JSON.
