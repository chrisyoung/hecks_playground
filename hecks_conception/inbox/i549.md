# i549 — View-mode filter : customer / driver / operator

## Why this card exists

The walking skeleton shows everything to everyone. SystemTest sits
next to Account, CreditCardProcessing.AttachPaymentMethod next to
Subscription.Subscribe. There's no narrative of "as a customer you
do these things" vs "as a driver you do these things."

The bluebook ALREADY declares `role "Customer"` / `role "System"` /
`role "Driver"` on every command. The renderer just doesn't filter
by it.

## What changes

**Top-bar role switcher** (next to the domain selector from i547) :

```
View as:  [Customer] [Driver] [Dispatcher] [Admin] [Operator] [All]
```

Click filters the aggregate grid and sidebar to show only
aggregates that have at least one command for the selected role.
Default "All" preserves today's behaviour.

State persists per-user in localStorage. The selection also
narrates the diagram view — same filter applies there, dimming or
hiding command/event/policy nodes outside the selected role's
trace.
