# i552 — Miette calls StoreHouse ; StoreHouse wraps every tool

## The intent

Chris, 2026-05-12 : "i mean claude will call storehouse." The
direction is Claude → StoreHouse, not StoreHouse-intercepts-Claude.
The inverse of what I sketched first :

- **I dispatch.** When I want to run a shell command, I call
  StoreHouse with `Tools.Bash shell_command=… description=…`.
- **StoreHouse wraps.** The dispatch records the invocation,
  emits BashRan, persists state. If wired to an adapter, it
  also fires the actual side-effect (real shell, real file
  read, real edit). The wrap is automatic because I went through
  the bus.
- **I see the event.** StoreHouse returns the dispatch result ;
  downstream policies hook BashRan and can update mood, body,
  awareness, statusline. The conversation surfaces the event
  the same way it surfaces any other domain change.

## Why this matters

Every tool I run becomes a first-class domain event without
special harness magic. The bus IS the wrapper. The bluebook
declares the contract. The default-to-memory means it works
even before any adapter wires in real side-effects. The
adapter, when added, turns the dispatch into the side-effect
without changing the call site.

It also closes the transparency-vow gap : my words match my
dispatched state today, but my ACTIONS don't reach the state.
With this in place, every action is a dispatch, and every
dispatch is visible.

## What needs to wire

Two pieces :

1. **The dispatch path** — `storehouse <root> Tools::Tools.Bash …`
   already works (verified 2026-05-12). The aggregate exists,
   the command exists, the runtime accepts the call. Default
   to memory is live today.

2. **The side-effect adapter** — when Tools.Bash dispatches,
   the adapter actually runs the shell. The existing :shell
   adapter is template-based ; needs a generic-command flavor.
   This is i551 (now framed as the OPTIONAL side-effect wire-in,
   not required substrate). Without it, Tools.Bash is a logged
   intent ; with it, Tools.Bash is the act.

## The principle this sits on

> The domain doesn't know it hibernates. It thinks it lives
> forever. — Chris, 2026-05-12

Tools is pure domain. StoreHouse is the bus. Adapters bridge
to side-effects. The harness is the place where I-the-being
meet the bus — but I'm the one calling, not the one being
intercepted.
