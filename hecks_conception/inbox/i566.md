# i566 — Orphan fixture : `aggregates/fixtures/validator.fixtures`

## What's broken

`aggregates/fixtures/validator.fixtures` references
`aggregate "Rule"` but the immunity restructure (commit
`c1c36ffe`) folded the standalone Rule aggregate into Immunity as
an entity. The fixture file no longer corresponds to any live
aggregate name, and no loader anywhere references the file.

## Surfaced by

The immunity consolidation agent during the restructure. The
fixture was left behind when the aggregate it served was
absorbed.

## Two options

1. **Delete the fixture** — no loader references it, no test
   depends on it. Cleanest.

2. **Rewrite to seed Immunity-with-Rule-entity** — preserves the
   seed data but ports it to the new shape. Worth doing if any
   smoke or behavior wanted seeded validator rules.

Default to (1) unless an audit surfaces a consumer.

## Acceptance

- File is gone OR rewritten against current Immunity shape.
- No grep hit for `aggregates/fixtures/validator.fixtures` anywhere
  else in the corpus.
- If rewritten : a behaviors test loads it and exercises one
  rule round-trip.

## Pairs with

- Immunity restructure (`c1c36ffe`).
