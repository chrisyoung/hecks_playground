# i568 — Lifecycle-tracked VO must carry `default:` matching initial state

## What this card carries

When an aggregate's lifecycle tracks an attribute that is wrapped
as a value object, the VO MUST declare a `default:` clause whose
value matches the lifecycle's initial state. Otherwise the
dispatcher (see i563) has nothing to return on readback before
the first transition, and you get `'[0 items]'` instead of the
expected scalar.

## Surfaced 5× tonight

- **Console.Speaker** — `status` lifecycle, wrapped as
  `SpeakerStatus` VO, no `default:` (cli/integrations sweep
  `3d9c61b3`).
- **Cli.Invocation** — `phase` lifecycle, wrapped as
  `InvocationPhase`, no `default:`.
- **Page** — `status` lifecycle, wrapped as `PageStatus`, no
  `default:`.
- **Generation** — `status` lifecycle, wrapped as
  `GenerationStatus`, no `default:`.
- **TrainingPair** — `coverage_status` lifecycle, wrapped as
  `CoverageStatus`, no `default:` (runtime/ sweep `8f927a58`).

Each had to be patched ad-hoc by the agent that hit it.

## Fix shape — macrophage check

A new macrophage check (let's call it
`lifecycle_tracked_vo_missing_default`) :

For every aggregate :
  For every `lifecycle :foo` block :
    Let `attr` = the aggregate attribute that `:foo` tracks.
    If `attr.type` is a VO :
      Require `attr.type` to declare `default: '<initial-state>'`
      where `<initial-state>` is the lifecycle's first
      `transition_from :nil` (or the documented initial state).
    Else (primitive attr) :
      No check.

## Acceptance

- Macrophage check fires on any new lifecycle-tracked VO without
  a matching `default:` clause.
- Check has a clear error message naming the attribute, the VO,
  and the expected default value.
- The 5 sites listed above either already have the default
  (landed in `3d9c61b3` / `8f927a58`) or are caught by the new
  check on re-run.
- Doc comment + behaviors test for the check itself.

## Pairs with

- **i563** — the runtime support side. i563 is the kernel making
  VO lifecycle attributes work ; i568 is the discipline check
  making sure they're declared correctly.

## Open questions

- Should the check also enforce that ALL declared VO `default:`
  values appear as transitions in the lifecycle ? Possibly a
