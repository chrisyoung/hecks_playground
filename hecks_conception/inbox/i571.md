# i563 — VO-as-lifecycle-tracker support in the dispatch kernel

## What's broken

When a `lifecycle :foo` block tracks an attribute whose type is
a value object (rather than a primitive), the dispatch kernel
reads the attribute back as `'[0 items]'` instead of the scalar
default declared on the VO. The kernel currently assumes a
lifecycle-tracked attribute is a primitive scalar ; VO unwrapping
on the read path is absent.

## Surfaced by

Two agents during the no-primitive-envy sweep tonight :

- **cli/integrations sweep** (commit `3d9c61b3`) — Console.Speaker
  status, Cli.Invocation phase, Page status, Generation status, and
  TrainingPair coverage_status each tried to wrap their lifecycle
  attribute as a VO. The dispatcher's readback failed.
- **runtime/ sweep** (commit `8f927a58`) — 14 residual primitive-envy
  errors across runtime/*.bluebook trace back to this. Each is a
  lifecycle attribute that wants to be a VO but can't be without
  the kernel support.

## Fix shape

Lift VO-with-default support into the dispatcher's lifecycle
readback path. The contract :

- `lifecycle :foo` declares an attribute that tracks lifecycle state.
- The attribute MAY be a VO (with `default:` clause matching the
  lifecycle's initial state — see i568).
- On readback, the dispatcher must unwrap the VO and return its
  scalar default until the first transition, rather than the
  `'[0 items]'` placeholder.

## Pairs with

- **i568** — make `default:` mandatory on lifecycle-tracked VOs
  (macrophage check). Naturally complements i563 ; i563 is the
  runtime support, i568 is the discipline gate.
- The 14 residual primitive-envy errors in `runtime/*.bluebook`
  sit on this. Unblocks closing the no-primitive-envy arc there.

## Acceptance

- `lifecycle :foo` blocks can name a VO-typed attribute.
- Readback returns the VO's `default:` scalar, not `'[0 items]'`.
- The 14 runtime/ residuals close without lifecycle-attribute
  primitive-envy exemptions.
- A behaviors test covers : declare aggregate with
  `lifecycle :status` where `status` is a VO with `default: 'idle'`,
  read back unwritten attribute, expect `'idle'`.
