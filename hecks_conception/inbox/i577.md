# i577 — SSE adapter : live `EventEmitted` stream to the Living Diagram

**Filed:** 2026-05-12 (during i527 cascade-animation work).

## Why

i527 LivingDiagram now animates a glowing traveler dot along every
firing edge — but only for dispatches the diagram itself fires (the
animation is driven from the `cascade` array in the
`/domains/:name/dispatch` response).

When the runtime fires events from anywhere else — a daemon, a
cadence loop, an LLM dispatcher, a hecks_conception script — the
diagram doesn't see them. The graph stays still even though the
runtime is alive.

## What this would conceive

A `:sse` adapter primitive in the hecksagon parser + runtime,
mirroring the existing `:web` adapter primitive. The hecksagon
already names the future route :

```ruby
adapter :sse,
  name: :diagram_event_stream,
  get: "/diagram/:domain_name/events.sse",
  source: :event_bus,
  content_type: "text/event-stream"
```

Runtime side : when registered, the runtime's `EventBus` gains a
subscribe-broadcast hook ; every `EventEmitted` (regardless of
which entrypoint fired the originating command) flushes a one-line
`data: {...}\n\n` frame to every connected client. The diagram's
JS adds an `EventSource('/diagram/:name/events.sse')` and routes
each `EventEmitted` to the same `runSteps` machinery already used
for the response-driven cascade.

## Acceptance

  - `:sse` adapter parses in both Ruby and Rust hecksagon parsers
    (parity-byte-equal).
  - Runtime registers the route and broadcasts every event to all
    subscribers without blocking the dispatch path.
  - Diagram subscribes on load ; an out-of-band dispatch
    (e.g. `storehouse repl` in another terminal, or a daemon firing
    a policy) animates the cascade in the open diagram tab.
  - The hecksagon's "Future" block at the bottom of
    `runtime/living_diagram/living_diagram.hecksagon` becomes the
    "Current" block.

## Out of scope

  - Multi-tab fan-out (more than one subscriber per domain).
  - Reconnect / backoff. The first cut can drop connections on
    disconnect and let the browser's EventSource reconnect.
  - Cross-domain SSE merging in the universe view ; that lands
    when the universe view itself gets a dispatch endpoint.

## Relationship to other work

  - **i527** parent — completes the cascade-as-living-imagery vision.
  - **i550** explorer codegen — sibling ; the SSE adapter must
    ship in the generated runtime too, not just the dev server.
