# i577 — Smoke-test bare-form regression after FQN gate landing

## What happened

The canonical `rust/target/release/storehouse` binary was overwritten
with a build from a worktree that adds `require_fqn_dispatch_address`
gates inside `loop`, `run-loop --dispatch`, and `clock`. The gate is
purely syntactic — it requires the address to contain `::` and prints
the message :

  loop : dispatch address 'Ultradian.EnterPeak' is a short-form
  address. The CLI requires the fully-qualified form
  Domain::Aggregate.Command ...

Six smokes in `hecks_conception/tests/` used bare-form addresses :

- `body_cycles_smoke.sh` — `loop ... Ultradian.EnterPeak,...` and
  `loop ... Heart.Beat` (twice)
- `dream_content_smoke.sh` — `run-loop ... --dispatch Dream.GatherSeeds`
- `interpret_dream_smoke.sh` — `run-loop ...
  --dispatch DreamInterpretation.GatherDreamCorpus`

These broke when the binary was swapped. Three of them were the
"masked $HOME fallback" cases from i565 ; the failure mode was easy
to miss because the failure surface was the symptom (parse / load
failure) rather than the cause (rejected dispatch address).

## The fix

Use FQN form everywhere the smokes invoke `loop` / `run-loop
--dispatch` / `clock`. Resolution is by `.split('.').last()` so the
domain prefix is documentation, not routing — but use the bluebook's
declared `category` for accuracy :

- Body cycles (heart, ultradian) → `Body::Ultradian.EnterPeak` etc.
- BodyDream / Dream singleton → `Body::Dream.GatherSeeds`
- DreamInterpretation → `Mind::DreamInterpretation.GatherDreamCorpus`

## Pairs with

- **i565** — same commit. Sibling-repo path resolution + FQN form
  both landed together because the smokes had to be re-tested after
  the path fix, and the bare-form failures only surfaced once the
  bluebooks were correctly linked.
- The FQN gate landed in a separate worktree (search `require_fqn_
  dispatch_address` in `.claude/worktrees/agent-ab63811a95c348fd1/
  rust/src/main.rs` for the source).

## Followup

Audit `.behaviors` test runner and other CLI surfaces that dispatch
by short-form name to ensure they're FQN-clean. Spot-check : the
`dispatch` subcommand (bare `storehouse <agg-dir> <Cmd>`) still
accepts short-form because it doesn't go through
`require_fqn_dispatch_address`. If FQN is to be enforced
universally, that path needs the gate too.
