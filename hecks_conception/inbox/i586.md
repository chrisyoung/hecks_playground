# i586 — OPT iconography : extend dividers across the site

## What Joey sent

Gmail thread "updates 5" at 2026-05-12T19:58Z, with a screenshot showing the existing iconography divider :

> I love how you have this iconography across the page. can we add more of these dividing up each section on the pages throughout the website as long as it doesnt make it too cluttered looking.

## Decision

Yes — extend, **sparingly**. One divider between major sections, not between every block. The point is to use the divider as a quiet section punctuation, not as a recurring ornament.

## Where it lands

- Homepage : between hero, group-fitness, 1-on-1, testimonials, recovery (when that page links here)
- About page : between Our Story, Our Mission, Values
- Other pages : 1 divider per major section break

Skip dividers on dense content pages (FAQ, schedule) where the structure already speaks.
