# i625 — Autophage : NavSitemapParity

## What

A new autophage that triggers whenever a site-nav module changes (e.g.
`footer.js`, `subnav.js`, or any file that exports a LINKS-style array)
and confirms the sitemap.xml entries match the new nav surface.

Failure mode this catches : we add a page to the nav, forget to add it
to sitemap.xml. Pages exist on the site but aren't crawl-able, SEO is
silently degraded, the site looks complete from the visitor's side but
not from Google's.

Inverse failure : we remove a page from the nav, leave it in sitemap.xml,
the sitemap points at a dead URL.

## Why this is an autophage, not a macrophage

Macrophages enforce structural rules at write-time (bluebook-first,
LoC ratchet, identity discipline). Autophages WATCH state and signal
when something drifted from where it should be. NavSitemapParity is
the second category : it isn't blocking an edit, it's noticing a
contract violation in deployed state.

The macrophage family stays at 12 (the disciplines we won't break) ;
this is the first in a new autophage family.

## Family naming

We name our discipline cells after biology :
  - Macrophage : ingests broken bluebooks, prevents commits
  - Antibody : binds to drift signatures, surfaces in CI
  - Autophage : self-eats inconsistent state, reports the gap
  - Fibroblast (i626) : the repair cell ; closes what the autophage
    finds

## Shape

```
aggregate "NavSitemapParity" do
  attribute :site_root, Path
  attribute :nav_modules, list_of(Path)
  attribute :sitemap_path, Path
  attribute :last_check_at, Time
  attribute :drift, list_of(NavSitemapDrift)

  command "Check"           # walks nav modules + sitemap, populates drift
  command "Clear"            # drift reconciled by Fibroblast or human
  command "Snapshot"         # records the last-known-good state

  query "current_drift" do
    description "Every NavSitemapParity where drift is non-empty"
  end
end

value_object "NavSitemapDrift" do
  attribute :path, String
  attribute :nav_present, Boolean
  attribute :sitemap_present, Boolean
  attribute :discovered_at, Time
end
```

## Closes when

  - Bluebook lives at `aggregates/discipline/autophage/nav_sitemap_parity/`
  - Heartbeat dispatches Check at minute boundaries
  - Drift surfaces in the additional-context channel on first turn
  - Cross-reference to i626 (Fibroblast) so the closing handoff is wired
