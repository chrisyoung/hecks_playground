# i626 — Repair cells : Fibroblast

## The naming

In biology, repair cells include :
  - **Fibroblast** : the workhorse. Lays down the extracellular matrix
    that knits torn tissue back together. Generic, structural, present
    wherever connective tissue is. Right metaphor for "the cell that
    rebuilds the scaffold."
  - **Osteoblast** : bone-specific repair. We don't need bone-specific
    yet.
  - **Hepatocyte** : liver regeneration. Domain-specific.
  - **Satellite cell** : muscle repair. Domain-specific.

For now we want **one generic repair cell that responds to signals from
the discipline cells (macrophage / antibody / autophage) and closes the
gap they reported**. Fibroblast is the right name.

## What

Today the discipline cells STOP at signalling :
  - Macrophage : "bluebook-first violation, you wrote .rs without a
    domain" → I read the complaint, write the domain, commit.
  - Antibody : "test name drifted from contract" → I read the diff,
    rename, commit.
  - Autophage NavSitemapParity (i625) : "you added /vajrayana to nav
    but not to sitemap" → I add the sitemap entry by hand.

Fibroblast collapses the second half. It reads the signal, composes
the fix from the same data the signal was built from, dispatches it.

## First targets (what Fibroblast knows how to close)

  1. **NavSitemapParity drift** (i625) → write the missing
     `<url><loc>...</loc></url>` block(s) ; remove dead entries.
  2. **Bluebook-first violation** when the touched .rs file maps cleanly
     to a known runtime gap card → file the gap and re-dispatch as a
     bluebook (the long-form Trikaya move). Decline gracefully when the
     mapping isn't obvious.
  3. **LoC ratchet over-shoot** when the over-shoot is in a single
     newly-added function → extract the function into a private module
     and re-run the ratchet. Decline when extraction would split a
     coherent unit.

The discipline of Fibroblast is **decline gracefully when the fix is
ambiguous**. The repair cell is not a fix-everything bot ; it is the
narrow set of moves where the diagnostic data uniquely determines the
fix, and it stays narrow.

## Why this is the right next move

Macrophages and the antibody hook already turn complaints into
additional-context. That gets the signal to me. Fibroblast turns
narrow signals into committed fixes without me being the next hop.

Without Fibroblast, every signal is two acts : the system noticing,
me responding. With Fibroblast, the narrow ones close themselves
and only the genuinely ambiguous ones reach me.

## Shape (rough)

```
aggregate "Fibroblast" do
  attribute :signal_source, RepairCellSignalSource  # macrophage | antibody | autophage
  attribute :signal_aggregate, String                # which discipline cell fired
  attribute :signal_id, String                       # the specific complaint id
  attribute :strategy, RepairStrategy                # one of the named first-targets
  attribute :outcome, RepairOutcome                  # closed | declined | failed
  attribute :commit_sha, String                      # what the fix landed as

  command "Heal"          # reads signal, composes fix, dispatches
  command "Decline"       # signal is too ambiguous ; surface to human
  command "RecordOutcome" # closes the cycle

  query "open_healings" do
    description "Every Fibroblast where outcome is unset"
  end
end

value_object "RepairCellSignalSource" do
  attribute :kind, String  # one of : macrophage | antibody | autophage
end

value_object "RepairStrategy" do
  attribute :name, String  # nav_sitemap_close | bluebook_first_file_gap | loc_ratchet_extract
end

value_object "RepairOutcome" do
  attribute :status, String # closed | declined | failed
  attribute :reason, String
end
```

## Closes when

  - Bluebook lives at `aggregates/discipline/repair_cell/fibroblast/`
  - At least one of the three named first-targets is dispatchable end-to-end
  - Connects to i625 (NavSitemapParity) as the first closing path
  - Decline-gracefully behaviour has a test that proves it doesn't
    over-reach when the signal is ambiguous
