# i639 — Clock as a bluebook capability (parser-first arc)

## Origin
i630 fixed VinDiction's wasm32 "time not implemented" panic by routing
dispatch sites through the hand-written #[cfg] helper heki::now_duration.
Chris : "Seems like it should all be bluebook. I don't know why it
would require kernel changes." Correct — raw SystemTime::now() in
runtime_shape snippets is the bluebook-first confession.

## What was tried this session (and what it proved)
Attempted part (a) : declare `Hecks.capability "clock"` in
framework/capabilities/clock.hecksagon. EMPIRICALLY BLOCKED :
- Rich DSL body (vision/kind/operation/adapter) → Ruby
  `Hecks::Capabilities::DSL` has no such methods (only description /
  direction / config / on_apply).
- Minimal `Hecks.capability "clock" do description ... end` → Ruby
  parity harness errors `undefined method 'name' for nil` : the Ruby
  capability DSL is a RUNTIME-REGISTRATION path (the retiring
  ruby/hecks/capabilities tree), not a parse-only declaration.
- Comment-only file → SAME error : the hecksagon-parity harness
  rejects any .hecksagon at framework/capabilities/ that doesn't
  register a capability object.
Conclusion : there is no native capability-hecksagon precedent
because the infrastructure does not support one. Part (a) is NOT
separable from part (b) — declaring the capability requires the same
parser Phase-2 work as projecting it. clock.hecksagon was removed
(an artifact that fails the parity gate is debt ; forcing it past
would mean pre-empting a known-drift exemption — forbidden).

## Corrected framing (three prior framings were wrong)
1. NOT a triggered adapter family (:exec/:mcp/:tts fire AFTER a
   matching dispatch ; clock is an INLINE primitive).
2. NOT specializer-time host/wasm forking (`specialize runtime`
   emits ONE runtime/mod.rs for host+wasm ; split stays
   #[cfg(target_arch)] resolved by rustc).
3. NOT a part-(a)-then-(b) split — (a) and (b) are one arc.

## The arc (one fresh focused session)
- **Parser Phase-2** : teach the Rust hecksagon parser AND the Ruby
  parity path to parse a `Hecks.capability` declaration as data
  (name, kind, operation, the :host/:wasm32 #[cfg] adapters,
  canonical_impl, contract) — parse-only, no runtime registration in
  the parity harness. The full contract is captured below.
- **Projection** : runtime_shape snippets + runtime::interpreter::emit
  reference the clock capability instead of raw SystemTime::now() or
  ad-hoc heki::now_duration(). Emitted call stays `crate::heki::
  now_duration()` (itself #[cfg]) — not a target fork. Byte-identity
  goldens (runtime, interpreter) reproven.
- **Enforcement** : a diagnostic-validator rule banning
  SystemTime::now()/Instant::now() in codegen/**/snippets/*.rs.frag +
  hand kernel-floor, sole exception heki::now_duration. COST : the
  validator layer is FIVE shapes (validator_shape,
  validator_corpus_shape, diagnostic_validator_meta_shape [emits
  lib/hecks_specializer/*.rb], validator_warnings_shape,
  lifecycle_validator_shape) — a multi-shape change, itself a
  bluebook-first confession (rules partly Ruby-emitting). Surfaces
  interpreter.rs:402 (closes i7) + test-only sites (named-exempt).

## The capability contract (design of record)
  name            clock
  kind            substrate
  operation       now_since_epoch -> std::time::Duration
  adapter :host   cfg not(target_arch="wasm32")
                  impl SystemTime::now().duration_since(UNIX_EPOCH)
                         .unwrap_or_default()
  adapter :wasm32 cfg target_arch="wasm32"
                  impl Duration::from_millis(worker::Date::now().as_millis())
  canonical_impl  crate::heki::now_duration
  contract        no codegen/**/snippets/*.rs.frag and no hand
                  kernel-floor file calls SystemTime::now()/Instant
                  ::now() directly ; all route through canonical_impl ;
                  heki::now_duration is the sole exception.

## Why carded not done
Parser Phase-2 + 2 specializers + 5-shape validator, byte-identity
coupled. Starting it at the i630 session tail is the documented
lost-hours pattern (i643/i645) — empirically re-proven across this
session, including this attempt. Design is locked ; execution is
mechanical from a fresh session.

## Closes when
A parsed `Hecks.capability "clock"` declaration is consumed by the
runtime/interpreter projection ; no SystemTime::now()/now_duration
refs in runtime_shape frags or interpreter emit ; ban validator green
(host+wasm goldens) ; VinDiction + bin-buddy still dispatch ok ;
i7 archived.
