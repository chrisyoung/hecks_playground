# i643 — PreToolUse lockdown hook hardcodes the allow-list (no domain sourcing ; no Violation.Record)

## Finding
EnforcementAdapter claude_code_pretooluse_lockdown is registered
(target : parent-repo .claude/settings.json#hooks.PreToolUse). The
hook itself : inline Python, default-deny, allow-list = the literals
mcp__storehouse__* / AskUserQuestion / ToolSearch. On deny it returns
a permissionDecision but dispatches nothing — no
Governance::Violation.Record. It never reads Policy.permitted.

## Why it matters
Governance vision : an act that emits no bus event cannot be governed,
and the denial itself becomes a governed, logged fact. A hardcoded
Python copy of the allow-list is the same anti-pattern as i641 hand-
written prompt section — domain truth duplicated into its surface.
The hook drifts from Policy.permitted ; denials are never logged as
Violations, so the audit trail the domain promises does not exist.

## State (honest)
- Policy claude_code_session : active, deny_by_default, hard_block,
  permitted[3].
- EnforcementAdapter : registered, NOT live — Claude Code requires
  hook review before execution ; native Bash/Read/Edit ran freely all
  session, proving the hook is not enforcing. MarkLive deliberately
  withheld (words match state, i52).

## The cure (shared with i641)
The :system_prompt capability (i641) generalizes render-a-surface-
from-Policy-state. The hook is another consumer of the same
principle : its allow-list must be GENERATED from Policy.permitted
(no Python literal) and a denied native call must dispatch
Governance::Violation.Record. A PreToolUse hook cannot itself
dispatch through storehouse mid-call → the Violation.Record is a thin
harness-gap adapter (the bluebook vision already names this honestly).
Depends on i642 (durable Policy) + i641 (the generation path).

## Closes when
The hook allow-list is generated from Policy.permitted (no Python
literal) ; a denied native call dispatches Governance::Violation.
Record and the Violation is queryable ; EnforcementAdapter MarkLive
is called only once Claude Code actually executes the hook.
