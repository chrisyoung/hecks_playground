# Per-utterance speed attribute

Add an optional `:speed` attribute (Float, default 1.1) to `Voice.Speak`. Apply a content heuristic in `speech_stream` to tag each statement with an appropriate speed before dispatch.

## Heuristic

| Content type | Speed |
|---|---|
| Long technical prose | 1.0 |
| Conversational | 1.1 |
| Headers / lists | 1.1 |

The heuristic lives in `speech_stream_advance.py` and sets `speed` on each `AppendStatement` dispatch.

## TTS adapter change

The TTS adapter passes the per-utterance `speed` value to ElevenLabs rather than using the hecksagon default. This makes speed a first-class attribute of each speech act, not a global setting.

## Dependency

Can be implemented independently of i673 (voice config lift), but pairs naturally with it — once config is in the aggregate, the per-utterance override becomes a clean delta on top of a known default.

## Scope

~30 min. Python + bluebook attribute change. Thin adapter wiring.
