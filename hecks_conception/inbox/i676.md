# ProcessMacrophage rule : reap orphaned mindstream

Add a rule to `aggregates/discipline/process_health/process_macrophage.bluebook` that catches storehouse run-loop processes whose `--emit` target is a Consciousness BodyPulse driver running past their parent overmind session's lifetime.

## Background

On 2026-05-13, PID 2275 ran at 99% CPU for 8 days. It was a mindstream daemon that outlived its overmind supervisor. The Stop hook does `overmind quit` but does not reap launchd-reparented mindstream children. These become invisible zombies.

## Rule shape

- **Trigger**: session-stop AND at boot
- **Detection**: any process matching `storehouse run-loop --emit` whose parent tmux session is not the current overmind session
- **Action**: `SIGTERM` the orphaned process; log to `/tmp/macrophage-reap.log`

## Implementation notes

The rule should query `tmux list-sessions` to get the current session, then cross-reference against `ps aux | grep storehouse` PIDs. If the parent chain does not include the current overmind session's tmux PID, reap it.

## Scope

~60 min. Bluebook rule + small shell reaper script. Stop-hook wiring needed. Surface to Miette if it requires touching the Rust runtime.
