# speech_stream_advance hardcoded glob bug

`bin/speech_stream_advance.py`'s `discover_transcript()` hardcodes the glob path:

```
/Users/christopheryoung/.claude/projects/-Users-christopheryoung-Projects-hecks/*.jsonl
```

When Claude runs from `hecks/hecks_conception/` (a subdirectory), the encoded project path is `-Users-christopheryoung-Projects-hecks-hecks-conception`. The script picks up a stale transcript from the parent project instead of the current session.

## Fix

Derive the project encoding from `$PWD` at runtime:

```python
import os
cwd = os.getcwd()
encoded = cwd.replace("/", "-").lstrip("-")
glob_path = f"/Users/christopheryoung/.claude/projects/{encoded}/*.jsonl"
```

This makes `discover_transcript()` always point at the correct project bucket regardless of which subdirectory Claude is invoked from.

## Test

After the fix, confirm that launching from `hecks_conception/` picks up the current session's `.jsonl` and not any file under the parent `hecks/` project path.

## Scope

~15 min. Single Python file change, no dependencies.
