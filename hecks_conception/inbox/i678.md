# SessionStart hook silent failure root cause

On 2026-05-21 morning, no session-start artifacts materialized:

- `/tmp/wake_review_route.log` — absent
- `/tmp/overmind-session-start.log` — absent
- `/tmp/storehouse_boot_verify.log` — absent

The hooks either didn't fire or were killed before opening their redirects.

## Reproduction steps

1. Close Claude Code completely.
2. Reopen Claude Code in `hecks_conception/`.
3. Immediately watch `/tmp/` for the three files above.
4. Note which (if any) appear and at what timestamp relative to session open.

## Candidate root causes

- **Hook timeout** — the harness enforces a per-hook timeout; if boot is slow the hook may be killed.
- **Permissions on /tmp** — unlikely on macOS but worth checking with `ls -la /tmp/`.
- **Hook matcher mismatch** — if the hook's `matcher` pattern doesn't match the session event name, it silently skips.
- **Harness skip on continue-session** — the harness may skip `SessionStart` hooks when resuming a prior conversation rather than starting fresh.

## Deliverable

A written diagnosis in a follow-up card or direct report to Miette: which path failed, and a settings.json fix or hook script fix.

## Scope

~30–45 min. Investigation + one small fix.
