The current README is internal-development-oriented. Rewrite as a quick-start for newcomers : install, run the pizzas example, wire up a hecksagon, write a world file. The hecksagon section uses the hecksagon DSL (Hecks.hecksagon ... do ... end) not bluebook. The README is the front door ; nobody arriving for the first time should need to read this conversation to make pizza.
