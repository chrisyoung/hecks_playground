# Storehouse-only harness gate

Claude Code's settings.json currently allows arbitrary Bash, Read, Edit, Write, Grep etc as native tools. The Bluebook-First Standard means every shell call should route through Tools::ShellTool.Bash, every file edit through Tools::FileTool.Edit, every read through Tools::FileTool.Read, every search through Tools::SearchTool. Narrow the allow-list in ~/Projects/hecks/.claude/settings.json so native Bash/Edit/Write/Read are blocked and the harness only honours storehouse dispatches. The transition is gradual ; mark a date and start denying native tools by default.
