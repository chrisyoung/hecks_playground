# Stop hook bluebookification

The Stop hook in ~/Projects/hecks/.claude/settings.json runs gem build/install + overmind quit + session-restart card check + tail-speech-via-Voice.Speak as four separate inline Python+Bash blocks. Each of those is a domain concept that should be a bluebook command : SessionStop.RebuildGem, SessionStop.QuitOvermind, SessionStop.CheckRestartCard, SessionStop.SpeakLastTurn. The settings.json hook becomes a single storehouse dispatch ; the four sub-commands cascade through their adapters. Removes the inline-Python wedge from the harness config.
