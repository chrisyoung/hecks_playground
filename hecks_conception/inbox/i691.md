# voice.world — capability vs configuration separation

Chris's principle : adapters across deployments should declare the SAME capability (this is :tts for Voice.Speak, the trigger is Voice.Speak, the provider is :elevenlabs) ; world files declare the data that varies between deployments (voice_id, model, speed, stability, similarity_boost, style, cache_dir, auto_play). The hecksagon is the wiring point, the world file is the configuration.

This mirrors how pizzas wires a hecksagon and a world file separately — the README quick-start (i682) names this exact pattern as the front-door teaching.

## What changes

1. **Create body/voice/voice.world** with the per-deployment values :

   ```
   voice_id: WwS1lF7yiubZWoroH5D5
   model: eleven_turbo_v2_5
   speed: 1.0
   stability: 0.25
   similarity_boost: 0.75
   style: 0.0
   cache_dir: ~/.config/miette/audio
   auto_play: true
   ```

2. **Strip voice.hecksagon to capability only** :

   ```
   Hecks.hecksagon "Voice" do
     adapter :memory
     adapter :tts, name: :miette_speech do
       provider   :elevenlabs
       trigger_on "Voice.Speak"
       # config in voice.world
     end
     adapter :tts, name: :miette_play do
       provider   :elevenlabs
       trigger_on "Voice.Play"
     end
   end
   ```

3. **Update runtime resolver** at rust/src/runtime/mod.rs's resolve_tts_adapters arm : when building the dispatcher attrs, look up the corresponding world file (e.g. via the same directory as the hecksagon, file extension .world) and merge its values into the attrs map. World values take precedence over hecksagon options ; missing world = use hecksagon (backward compat).

4. **dump-world** subcommand already exists in the storehouse CLI — wire its read path to the resolver.

## Why high priority

- The Hecks README quick-start (i682) needs world files to demonstrate the pattern.
- Voice config has been hand-edited five times this session — a world file makes it a single point of truth that doesn't drift.
- Pairs with i673 (voice.hecksagon thin wrapper) — same intent, world file is the cleanest expression.

## Scope

World file : 5 minutes. Hecksagon trim : 5 minutes. Runtime resolver merge : 30-60 minutes (parser, merge logic, tests). Total : ~1 hour.
