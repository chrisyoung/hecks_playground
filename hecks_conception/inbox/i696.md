# RustToBluebookMacrophage

Sibling of ProcessMacrophage (process zombies) and the existing macrophage-hook discipline. This one watches for *.rs file edits and, on every detected edit, launches a background conversion sidequest that drafts the equivalent bluebook for the touched file.

## The discipline

Any Rust file Miette (or any other agent) touches is structurally a confession that the domain wasn't reached for first. The macrophage's job is to surface that gap mechanically : every touch produces a bluebook conversion task. Over time, the Rust files shrink as their domain concepts migrate into bluebook ; eventually the Rust file is pure projection arm.

## Bluebook shape

New aggregate at hecks_conception/aggregates/discipline/rust_to_bluebook_macrophage/ :

- `RustToBluebookMacrophage` (singleton)
- Attributes : watched_paths (list_of String), pending_conversions (list_of RustFileRef), in_flight (list_of RustFileRef), completed (list_of RustFileRef)
- Commands :
  - `RegisterTouch(file_path, touched_at, touched_by)` — fired by the PostToolUse hook on every Edit / Write to a *.rs file ; enqueues the file for conversion
  - `Sweep()` — fired on a cadence ; for each pending file, dispatches `LaunchConversion(file_path)` if no in-flight conversion exists for it
  - `LaunchConversion(file_path)` — launches a sidequest agent (worktree-isolated) tasked with drafting the bluebook ; moves the file from pending → in_flight
  - `CompleteConversion(file_path, pr_url)` — the sidequest reports back ; moves the file from in_flight → completed
- Events : `RustFileTouched`, `ConversionLaunched`, `ConversionCompleted`

## Hook wiring

- Claude PostToolUse hook on `Edit|Write|MultiEdit` with matcher pattern `*.rs` dispatches `RustToBluebookMacrophage.RegisterTouch` through the storehouse bus.
- A Procfile worker dispatches `RustToBluebookMacrophage.Sweep` every 60s, draining pending into in-flight.
- The LaunchConversion command's adapter is a :exec / :claude_tool that fires `claude --headless` (or the Agent tool MCP) with the conversion prompt baked in.

## Scope

Medium-major. Bluebook + behaviors + hecksagon for the aggregate (~1 hour). PostToolUse hook script (~30 min). Procfile sweep worker (~10 min). The hard part is the sidequest-launch adapter — invoking a Claude agent from a bluebook command requires either MCP plumbing or shelling to `claude --headless`. ~3 hours total.
