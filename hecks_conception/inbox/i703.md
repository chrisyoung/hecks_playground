# i703 — restart_prompt Procfile entry points at a missing binary

`Procfile` has `restart_prompt: bin/restart-prompt-daemon` but that file no
longer exists in `hecks_conception/bin/` (only inbox_poll.mjs,
process_health_heal.mjs, speech_stream_advance). On `overmind start` the
worker exits 127 ; because it isn't in `OVERMIND_CAN_DIE=boot`, overmind
tears down ALL daemons. Disabled the line (commented out) to restore the
body. To properly fix : either rebuild/restore the restart-prompt daemon and
re-enable, or remove the member from the mindstream fixtures (the Procfile is
hand-derived from aggregates/framework/mindstream/mindstream.fixtures, i262).
