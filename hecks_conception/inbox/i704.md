# i704 — consciousness pulse loop runs a stale binary (old breadcrumb log format)

The mindstream BodyPulse driver (`storehouse run-loop ... --emit
BodyPulse:Consciousness:consciousness`, PID seen as 4262) has run since boot
and survives `overmind restart` because it is NOT an overmind Procfile worker
— boot reports "mindstream: already running". It therefore still runs the
pre-flat-stream binary and writes OLD per-event breadcrumb lines
(`[ts] cascade X#id ok=true`) to the storehouse log. `storehouse follow`
ignores them (they don't match the flat `[Domain Aggregate Command]` shape),
so they're harmless to the watcher — but consciousness activity is invisible
in follow and the lines are on-disk noise. Fix : restart the mindstream pulse
on the current binary (state is persisted in consciousness .heki, so a restart
resumes cleanly), and make it a managed worker so future binary swaps pick it
up. Until then consciousness won't show in the flat follow stream.
