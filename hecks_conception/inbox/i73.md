# i73 — inbox-auto-commit-staging-area-conflict

inbox-auto-commit-staging-area-conflict — Residual after the 2026-04-25 inbox-push-to-main fix. The auto-commit step (existing since PR #427) does `git add $HEKI; git commit` which packages whatever was already staged in the index along with the heki update. When the operator has unrelated files staged from prior work, those get bundled into the inbox($ref) commit. Surfaced 2026-04-25 when the i70 filing's auto-commit silently picked up several lib/hecksagon/* files that were staged from i67 work. Fix : either (a) git stash the index before commit and pop after, (b) use git commit -- $HEKI to commit only that path explicitly bypassing the index, or (c) separate the inbox.heki write from the operator's index entirely. Option (b) is simplest. Cost : changes one line in inbox.sh.
