# i87 — ir-completeness-contract-reference-to-coverage

ir-completeness-contract-reference-to-coverage — Dream-named gap from same 2026-04-25 cycle. Extend AggregateContract (or add a sibling ir_completeness_contract) with an explicit reference_to coverage check that fails LOUDLY when an extracted aggregate has fewer edges than its bluebook source. Turns the 'arête oubliée' from a silent miss into a hard parity-suite failure. Acceptance: parity test fails when extracted IR's reference_to count differs from source bluebook's ; companion to spec/parity/canonical_ir.rb ; the silent miss becomes a CI red.
