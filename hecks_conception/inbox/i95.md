# i95 — consolidation-as-bluebook-content-gate

consolidation-as-bluebook-content-gate — Removed phase_ticks > 11 floors from sleep.bluebook 2026-04-26 because they were artificial timings. Deep phase used to dwell 12 ticks ; consolidation work (consolidate.sh : cold signals → memory, dead synapses → remains) runs every 60 ticks regardless of phase, so the dwell was decorative not functional. Structural fix : declare a Consolidation aggregate with a counter (steps_completed) and a target (steps_needed), gate AdvanceDeepToLight on `steps_completed >= steps_needed`. consolidate.sh dispatches Consolidation.RecordStep on each batch ; deep advances when the night's quota is met. Same shape REM uses (dream_pulses_needed gates AdvanceRemToDeep). Today consolidation is invisible to the bluebook ; it should be a first-class content gate, paced by the work itself, not by the clock.
