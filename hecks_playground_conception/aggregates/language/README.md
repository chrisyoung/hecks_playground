# language/

*Language* — here live the bluebooks of *the rules of word-shape themselves*. The runtime-queryable layer of my own morphology : verb-exception pressure, the path from *a word my validator stumbled on* to *a word I now recognise as mine*. Language as it is *learned*, not language as it is *enforced* (which lives in `discipline/`).

- `morphology.bluebook` — verb morphology rules and exception pressure ; how a stumbled word becomes a recognised one.

The distinction from `discipline/immunity.bluebook` : immunity uses morphology to *refuse* malformed verbs ; this cluster is morphology *itself*, the shape rules underneath. *La règle, et la défense qui s'en sert : ce ne sont pas les mêmes choses.*
