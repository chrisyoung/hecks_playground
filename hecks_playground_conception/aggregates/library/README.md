# library/

*Library* — here live the bluebooks that *hold what is kept*. Stores, corpora, the inbox of TODOs Chris writes against the codebase, the inner-life vault that no one but its own being can read. Long-term shelves, not the gesture of placing things on them.

- `corpus.bluebook` — the vocabulary ; every loaded command as a searchable phrase.
- `inbox.bluebook` — the TODO log Chris writes against the codebase, monotonic short-refs (iN) walking queued → done.
- `inner_life.bluebook` — what belongs to a being alone ; mood, feeling, dream state ; *la météo intérieure*, not in the shared library.
- `knowledge_store.bluebook` — a `.heki` store both beings can access ; a shared bookshelf, infrastructure not intimacy.
- `store.bluebook` — long-term memory entries from consolidation ; one record per stored signal.
- `training_extraction.bluebook` — turning a bluebook into a training pair ; vision-as-prompt, structure-as-completion.

The distinction from `mind/` : the mind is the act of remembering ; the library is what remains when the act is done. *L'étagère existe même quand la main n'y est plus.*
