# i753 -- generated Rust: VO-wrapped attribute default emits as a bare literal

## What's wrong

    error[E0308]: mismatched types
      --> src/generated/demo/demo.rs:575:44
       |
    575 |         record.current_slide_number = Some(1);
       |                                       ---- ^ expected `SlideNumber`, found integer

`current_slide_number` is `Option<SlideNumber>` (a value object wrapping
`attribute :value, Integer`, presumably with a numeric default declared
somewhere in `demo.bluebook`). The generator's default-value codegen
emits the raw default (`1`) directly, not wrapped in the value object's
own constructor (`SlideNumber { value: 1 }`).

## Where to look

`vendor/hecksagain/rust/project/` -- likely `fielded.rb` (attribute/
default-value emission) or `domain_generator.rb`. The FIX pattern is
visible in the SAME generated file for non-defaulted assignments
elsewhere (real VO construction works fine when it's not a default) --
so this is specifically the default-value code path not routing through
the same VO-wrapping logic normal field construction already uses
correctly.

    cd vendor/hecksagain
    ruby bin/project_rust /path/to/hecks_playground_conception/aggregates/demo
    cd rust && cargo build

Should compile clean (currently 1 error from this, matching the E0308
above -- re-check the FULL error list once fixed, since i754's Status
